# AgenC 0.19.35

AgenC 0.19.35 makes Light faster on OpenAI models: a session keeps one WebSocket open to OpenAI and sends every model
call over it, so each call starts sooner and sends less. This is the default on the OpenAI API and with ChatGPT
sign-in. Gemini gains Gemini 4 Hydrogen, an up-to-date model list, images from tool results and a faster token count.
OpenAI's freeform edit tool is available as an opt-in.

## OpenAI

- Light sessions of the `openai` provider send their model calls over one WebSocket per session instead of one HTTP
  request per call. The wait for the first event of a call fell from 0.38 to 0.11 s on the OpenAI API and from 0.81
  to 0.39 s with ChatGPT sign-in. On GPT-6.1 Terra and Sol a run was 5.6% faster than over HTTP in our measurement
  of 88 paired runs (#3575).
- The socket opens when the session starts, so the first call does not wait for the connect, and it reopens ahead of
  the next call when it is lost. In print mode (`agenc -p`) the first call still waits for most of the connect; the
  later calls gain (#3575).
- A call that continues the previous one sends only the new items (tool results, your message) and names the previous
  response. Bytes sent fell by two thirds in the measurement. AgenC sends the full input whenever the model, the
  instructions, the tools or the earlier history changed (#3575).
- The session returns to HTTP by itself when the socket cannot connect or the service refuses a call. After two failed
  connects in a row it stays on HTTP and shows one notice. Gateways, other remote hosts and sessions behind an HTTP
  proxy stay on HTTP. Other providers never open a socket (#3575).
- `[providers.openai] transport = "http"` or `AGENC_OPENAI_TRANSPORT=http` turns the WebSocket off.
  `transport = "websocket"` uses it for every session of the provider, not only Light ones (#3575).
- New opt-in: `[providers.openai] tool_format = "freeform"` or `AGENC_OPENAI_TOOL_FORMAT=freeform` declares
  `apply_patch` to GPT-5 and later models as an OpenAI freeform tool, so the model writes the patch as plain text
  instead of a JSON string. It is off by default: in our test it used 6 to 10% more tokens on GPT-6.1 Terra and Sol
  and showed no clear gain in time. The tool, its checks and its results are unchanged (#3576).

## Gemini

- Gemini 4 Hydrogen (`gemini-4-hydrogen`) is a known model: effort levels low, medium, high and xhigh (default high),
  65,536 output tokens, and its price ($1.50 per million input tokens, $7.50 per million output tokens) in the cost
  display. It waits up to 20 minutes for a silent response, like Argon and Carbon (#3577, #3578).
- The model list follows Google's API of November 15, 2026. `gemini-3-pro-preview` is gone (Google shut it down).
  `gemini-2.5-pro` and `gemini-2.5-flash` are hidden from the model list because Google deprecated them; a saved
  setting keeps working. The built-in fallback models are now `gemini-3.8-flash`, `gemini-3.5-flash-lite` and
  `gemini-3.1-pro-preview` (#3577).
- The aliases `gemini-pro-latest`, `gemini-flash-latest` and `gemini-flash-lite-latest` are accepted when Google's
  model list has them. An alias takes no effort setting and shows its cost as unknown (#3577).
- `gemini-3.1-flash-lite-preview` has its effort levels and a price again, and every Gemini 3 and Gemini 4 model is
  marked as a thinking model, not only Gemini 2.5 (#3577).
- An image in a tool result (a screenshot, an image file the model read) now reaches Gemini 3 and newer models. Before,
  the model got a note in place of the image and could not answer questions about it. This covers PNG, JPEG and WebP
  (#3578).
- The context size AgenC tracks for Gemini now includes the thinking that Google bills again on every later request.
  Google's token counter leaves it out, so the tracked size fell behind the billed prompt (#3578).
- AgenC no longer asks Google's token counter before every model call. A request no larger than half the context
  window is estimated locally, which removes a round trip of 90 to 210 ms per call. Larger requests, cached content
  and the summary check of a compaction still use Google's counter (#3578).

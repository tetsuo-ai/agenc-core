# AgenC 0.19.7

AgenC 0.19.7 makes every request in a standard session smaller again, and
retries a provider outage that answers with an HTML error page.

## Lighter requests

- The part of each request that AgenC resends on every model call is about
  40 percent smaller than in 0.19.6. On DeepSeek the first request of a task
  went from about 8,950 tokens to about 5,260.
- The system prompt states the same rules in fewer words. That includes the
  memory instructions, the permission and sandbox rules, and the section on
  helper agents.
- Tool descriptions are shorter. The shell tool and Grep are sent with the
  fields models use most. Every other field still works, and the full
  description loads when the model asks for it.
- AskUserQuestion and the plan mode tools load on demand. In plan mode the
  model can still ask you questions and present its plan for approval.
- The skill list shows at most 120 characters of each skill's description.
  The skill itself keeps its full text.
- On a small "make the failing tests pass" task with DeepSeek V4 Flash
  (median of 4 runs each), 0.19.6 took 25.9 s and 94,000 tokens. 0.19.7
  takes 25.2 s and 74,000 tokens.
- On a set of 10 everyday coding tasks, tokens fell about 37 percent, wall
  time about 12 percent and cost about 13 percent compared with 0.19.6. On a
  separate set of 12 held-out tasks, tokens fell about 42 percent, wall time
  about 11 percent and cost about 17 percent. All runs were solved on both
  sets, as with 0.19.6.
- Light sessions, and sessions with `defer_rare_tools = false`, are
  unchanged.

## Fixes

- During an outage, the gateway in front of an OpenAI-compatible provider can
  answer 502, 503 or 504 with an HTML error page. AgenC now retries that like
  any other server error. Before, the turn stopped and showed the page's HTML
  as the error.
- The system prompt no longer says that a turn continues until a token target
  such as "+500k" is reached. No part of AgenC did that.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.7`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

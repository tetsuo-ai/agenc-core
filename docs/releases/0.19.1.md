# AgenC 0.19.1

AgenC 0.19.1 fixes two problems found right after 0.19.0 shipped.

## Fixes

- New sessions have no task token cap by default. The default budget is now
  max. With the 0.19.0 default (balanced), a ChatGPT sign-in refused every
  model turn with `provider_budget_contract_unavailable`, because that backend
  cannot take a per-request output limit. Choose eco or balanced with `/budget`
  or `--budget` when you want a cap.
- A ChatGPT sign-in now works with a task budget too. That backend rejects a
  per-request output limit, so 0.19.0 refused every turn under eco or
  balanced. Admission now reserves the model's documented maximum output,
  which bounds every reply, and the budget applies as chosen.
- Starting AgenC in your home folder works again. There, the folder's `.agenc`
  directory is the AgenC home itself, so 0.19.0 could not load or save
  configuration and sessions ran on defaults. That directory is now read only
  as your user configuration.

## Upgrade notes

A budget you saved before is kept. Standalone installations update with
`agenc update`; npm installations with `npm install -g @tetsuo-ai/agenc@0.19.1`.
Then run `agenc daemon restart`.

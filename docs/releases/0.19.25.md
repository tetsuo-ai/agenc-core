# AgenC 0.19.25

AgenC 0.19.25 moves the daemon to a new version after an update and lets the TUI update in place. An older
`agenc` no longer stops a newer daemon. A stuck process cleanup pauses the shell instead of closing it, the
cost readout shows DeepSeek's off-peak price, DeepSeek sessions fetch pages through DeepSeek's Fetch API, and
seven TUI bugs are fixed.

## Updates and the daemon

- After `agenc update`, the daemon moves to the new version by itself. An idle daemon restarts right away. A
  busy one, with an attached TUI, a running agent, tool call, goal or background process, is left alone and
  restarts once it has been idle for two checks in a row, for up to 12 hours. Only daemons from 0.19.25 on
  restart this way; an older daemon keeps the old `agenc daemon restart` hint, as does Windows (#3354, which
  includes #3351).
- "Update now" in the TUI installs the update, restarts AgenC and comes back in the same conversation
  (#3354).
- An older `agenc` that is still open no longer stops a newer daemon. Before, after an update restarted the
  daemon on the new build, an older TUI starting a session stopped the newer daemon and started its own older
  runtime in its place. It now keeps using the newer daemon and prints once that the daemon runs a newer
  version, so quitting and starting `agenc` again uses the same version. A daemon older than the client is
  still replaced, as before (#3353).

## Print runs

- `agenc -p` served by a resident host now bounds the stop of its agent the way one-shot runs do since
  0.19.24: when the stop is not confirmed in time, the run prints the cleanup warning and keeps its result and
  exit code. Before, a stop that never settled kept the run from finishing (#3349).

## Shell

- When stopping a command cannot prove right away that all of its processes are gone, for example a
  `find` blocked on a slow external disk, the shell now pauses instead of refusing every later command for
  the rest of the session. AgenC checks again before the next command and reopens the shell once the
  processes are gone. While it is paused, the refusal names the command and the process still running, and
  the turn stops with that explanation instead of retrying (#3352).

## Cost readout

- The TUI cost readout shows an estimate of what DeepSeek bills. A call dispatched in DeepSeek's off-peak window
  shows its discounted price with `off-peak`, for example `$0.250 off-peak` for a $0.500 call. Each call
  counts at the time it was sent, so the figure no longer changes with the current clock. An eligible call
  without a dispatch time shows `peak est.`, and other figures keep their plain form. This applies to the
  DeepSeek API and QwenCloud DeepSeek routes. `/cost` shows both the accounting total and the billed
  estimate (#3356).

## DeepSeek web fetch

- In DeepSeek sessions, WebFetch reads pages through DeepSeek's Fetch API, the way web search already uses
  DeepSeek's Search API. It is on by default when the session uses DeepSeek's own API host. If the DeepSeek
  fetch fails for any reason, AgenC fetches the page locally instead. Each successful fetch costs $0.75 per
  1,000 and counts toward the session cost. The TUI row says `via DeepSeek fetch`. Local and private
  addresses never go to DeepSeek. Turn it off with `[providers.deepseek] web_fetch = false` in config.toml
  or `AGENC_DEEPSEEK_WEB_FETCH=0` (#3358).

## TUI fixes

- A question that asks for a free-text answer no longer crashes the options picker (#3357).
- The notice after a recovered submission is colored again (#3357).
- First-run AgenC key onboarding works on sign-in backends that cannot save the key themselves. It falls back
  to the local save (#3357).
- `$skill` messages are sent as proper user messages, images included (#3357).
- The paste confirmation shows its warning and confirmation colors again (#3357).
- A new `@file` attachment shows its details again (#3357).
- The IDE extension install notice follows the `ideConnector.autoInstallExtension` setting, so it no longer
  appears after you turn it off (#3357).

## Development

- Three CLI and prompt test files are now typechecked, and their 18 type errors are fixed. No assertion
  changed (#3350).
- The TUI sources are now part of the typecheck that runs before every release (#3357).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.25`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.

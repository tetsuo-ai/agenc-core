# AgenC 0.19.24

AgenC 0.19.24 fixes problems found while running AgenC on Terminal-Bench.
One-shot runs exit soon after they write their result. A run with a deadline
gets its time reminders on every path. Unattended Light sessions check the
delivered result against the request before they finish.

## One-shot runs

- After `agenc -p` writes its result, stopping the agent it started has one
  5 second budget. Before, with the daemon socket gone, the stop could wait 30
  seconds or more for a reconnect, so the process outlived its result (#3343).
- When the daemon has already exited, for example after `agenc daemon stop` at
  a deadline, the run stops waiting at once. A daemon that shut down has
  stopped its agents (#3343).
- When the stop cannot be confirmed in time, the run prints a warning on
  stderr. The result and the exit code are unchanged (#3343).

## Deadlines

- A run with `--deadline`, or an SDK or daemon run with `deadlineAt`, now
  always uses the standard turn loop. Before, `agenc -p` with approvals and
  sandbox bypassed took the faster one-shot loop. That loop sent no
  remaining-time reminder and no `time_remaining_sec` on tool results, gave no
  reserve warning and did not stop at the deadline; only the client stopped it,
  20 seconds later (#3344).
- The deadline reminders ask the model to write a minimal valid result at the
  requested path early, improve it on a copy, and never delete the working
  result before its replacement is ready. Runs without a deadline are
  unchanged (#3344).

## Unattended Light sessions

- Light print runs (`agenc -p`) and other unattended Light sessions keep a
  short acceptance checklist from the request: paths, formats, exact bytes and
  numeric bounds. Before finishing, they check the delivered result against
  it. Checks come from the request, a provided reference is used unchanged,
  and a missing check tool gets one time-bounded setup attempt. Interactive
  Light and standard mode are unchanged (#3345).

## Development

- The runtime maintenance test now stops its probe process before it removes
  the probe's folder. Before, each run of that test file left one stray
  process behind (#3346).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.24`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.

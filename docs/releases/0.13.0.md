# AgenC 0.13.0

AgenC 0.13.0 turns the terminal workbench into a unified Agent-and-Editor
coding workspace, adds safe AI-assisted Neovim editing, and makes Ledger setup
and authenticity verification first-class.

## Agent and Editor workspace

- Agent and Editor are sibling tabs in one workspace, sharing the canonical
  project, daemon session, conversation, queue, and lifecycle while preserving
  each tab's draft, attachments, focus, and side-panel state. Switch with
  `Alt+1`, `Alt+2`, or `Alt`+backtick.
- Embedded Neovim is a persistent, multi-buffer workspace editor. Buffers,
  undo history, registers, plugins, hidden changes, and native Neovim UI
  survive file navigation and Agent/Editor switching.
- `:AgenCAsk` and `:AgenCExplain` run daemon-enforced read-only turns.
  `:AgenCFix`, `:AgenCEdit`, and `:AgenCRefactor` create committed shadow
  proposals for explicit review instead of mutating the live buffer.
- Unsaved buffers and visual selections are captured exactly. Responses and
  proposals open in a scrollable Editor panel without replacing Neovim.
- Consent-gated code prediction adds inline ghost text without sending source
  before opt-in. `Tab` accepts a prediction and `Ctrl+Right` accepts the next
  segment.
- Save, exit, resume, project-tree mutation, disk conflicts, concurrent agent
  writes, dirty hidden buffers, and proposal teardown now use explicit safety
  gates and recovery paths.

## Ledger hardware wallets

- AgenC can install the official Ledger Wallet CLI into `AGENC_HOME` after
  approval, with registry-origin checks, SHA-512 verification, bounded
  extraction, and no global installation.
- `/ledger genuine-check` now has a dedicated device-verification popup. The
  success state requires an explicit authenticity result from the official
  CLI; a zero exit code alone is not accepted.

## Terminal experience

- Agent activity reports real tool, token, elapsed-time, approval, and
  selection state instead of implying a completion percentage.
- The command footer stays visible during long output, compact layouts are
  cleaner, and Kitty and portable terminal logos derive from the official
  AgenC mark.

## Reliability and compatibility

- Grok/xAI Responses requests use the accepted named-tool selector, fixing
  forced initial `spawn_agent` calls in parallel SWARM workflows.
- Standalone installers can safely replace authentic AgenC wrappers from
  0.6.2 through 0.10.0, and installer promotion retries are idempotent.
- Windows local daemon clients use a deterministic per-home named pipe.
  Neovim lifecycle and containment behavior is gated across all five native
  targets.

There are no breaking configuration, conversation, Unix socket, daemon
protocol, or SDK changes. Embedded editing requires Neovim 0.9 or newer;
`buffer.provider = "auto"` falls back to the inline editor when Neovim is
unavailable. Code prediction defaults to consent-on-first-use. Embedded Neovim
reserves `Ctrl+X`, `Ctrl+K`, `Ctrl+G`, and `Ctrl+R`; workbench navigation uses
the `Alt` shortcuts. `:AgenCReview` remains a compatibility alias for
`:AgenCRefactor`. The SDK remains independently versioned at `0.3.0`.

## Upgrading

```sh
agenc update                              # standalone installs
npm install -g @tetsuo-ai/agenc@latest   # npm installs
brew upgrade agenc                       # Homebrew installs
```

Restart an already-running daemon after updating:
`agenc daemon restart`.

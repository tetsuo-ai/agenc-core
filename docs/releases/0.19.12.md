# AgenC 0.19.12

AgenC 0.19.12 starts every new session in Light mode, which is now faster
and lighter on tokens. Read-only tool calls and long sessions are faster in
every mode. DeepSeek and GPT models reached through Ollama Cloud, OpenRouter
or Venice get the tuning AgenC uses on their own APIs, plus web search and
exact costs. Memory now uses each session's own folders, and a call the
sandbox refuses needs its own approval before it runs outside the sandbox.
The private Node.js runtime and undici get the October security fixes.

## Light is the default

- New sessions start in Light mode: `agenc`, `agenc -p`, sessions the daemon
  creates (`agenc agent start`, SDK and API clients, phone, Telegram and
  routines) and Goals (#3201).
- To use the standard mode, start AgenC with `--standard` or set
  `light_mode = false` at the top of `~/.agenc/config.toml`. `--light` still
  works and overrides that setting (#3201).
- A resumed session keeps the mode it started in (#3201).
- The status line shows `standard` for a standard session and no mode label
  for Light (#3201).
- In plan mode, Light lists AskUserQuestion and ExitPlanMode, so the plan
  approval card appears as in standard mode (#3201).
- A Light session lists your installed skills in its first request, so the
  agent can use them without being asked (#3201).
- AgenC Desktop still picks the mode of its own new sessions with its Light
  setting (#3201).
- If you rely on MCP tools or sub-agents, run `agenc --standard` (or set
  `light_mode = false`) to keep the previous behavior. Better guidance for
  them in Light comes in the next release (#3202).

## Faster and leaner Light mode

- Light accepts an edit to a file the agent already printed in full in the
  shell, so it no longer reads the file again first (#3154).
- Every Light request is about 195 tokens smaller, and tool search answers
  with one-line summaries (#3168).
- Light sends memory rules and product help only when a request needs them,
  and its tool schemas are shorter (#3182).
- On DeepSeek, Light does only what was asked, reruns checks only after new
  edits or failures, and reports in one or two sentences (#3162).
- On DeepSeek, Light's Edit applies several replacements to one file in one
  call (#3163).
- With DeepSeek Flash on DeepSeek's own API, Light edits with apply_patch, so
  the source, tests and docs of one change go out in one patch (#3190).

## Faster in every mode

- File reads, Grep, Glob and read-only shell commands skip the bookkeeping
  that makes edits crash-safe, so they return sooner (#3161).
- Piped and chained read-only shell commands use the same fast path, in a
  sandbox with no writes and no network (#3171).
- Grep and Glob reuse a warm search helper instead of starting one for each
  search (#3171).
- Read-only shell commands from one model response run side by side (#3182).
- Tool calls no longer wait on redundant sandbox checks and fixed delays
  (#3158).
- A checkpoint costs the same late in a long session as early on (#3165).
- Reopening a long session, admission checks and token counting no longer
  slow down as the session grows (#3167).
- AgenC no longer syncs to disk on every chunk of streamed tool output
  (#3191).
- GPT-6 Luna on the OpenAI API no longer requests a reasoning summary unless
  you set `reasoning_summary`, so its calls return sooner (#3189).
- A question that only needs information ends once it is answered, without
  a coding checklist or invented follow-up work (#3144, #3145).
- apply_patch accepts a file the agent already printed in the shell, without
  an extra read (#3146).
- Tool search ranks partial matches and returns at most five tools (#3149).
- The main agent collects finished helpers right away instead of polling
  with shell sleeps (#3156).
- In plan mode, an answer that needs no work finishes without a plan
  approval (#3156).

## Providers: Ollama Cloud, OpenRouter, Venice

- A DeepSeek or GPT model reached through Ollama Cloud, OpenRouter or Venice
  gets the tuning AgenC uses on DeepSeek's and OpenAI's own APIs (#3182).
- WebSearch works with an Ollama Cloud, OpenRouter or Venice key, through
  that provider's own search (#3182).
- On Ollama Cloud, WebFetch uses Ollama's web fetch with your key and falls
  back to a direct fetch (#3192).
- OpenRouter and Venice sessions can generate images and video and turn text
  into speech with their own key (#3182).
- Venice sessions can also edit and upscale images, and any media model on
  Venice's current list can be used at Venice's price (#3182).
- A Venice call costs what Venice reports with the reply (#3182).
- Ollama Cloud costs match what Ollama debits, including its per-result web
  search fee (#3187).
- With no effort set, Ollama Cloud and Venice send the model's own default
  effort, and the status line shows it (#3192).
- /effort can turn thinking off on Ollama Cloud and Venice models that
  support it (#3182).
- OpenRouter and Venice requests carry a prompt cache key, so later requests
  can reuse the cached prompt (#3182).
- The /providers screen tags each model with vision, thinking, no tools,
  free or its retirement date (#3182).
- The Venice model list is shared across sessions for 10 minutes, and an
  inference error no longer drops it (#3192).
- The bundled OpenRouter catalog matches OpenRouter's list of October 21,
  with 298 models (#3192).

## DeepSeek, OpenAI and other providers

- On DeepSeek's own API, WebSearch uses DeepSeek's Search API with the same
  key; set `web_search = false` under `[providers.deepseek]` to turn it off
  (#3140).
- Search providers you configure, such as Tavily or Exa, and the
  `AGENC_WEB_SEARCH_*` settings now reach the agent's WebSearch tool (#3140,
  #3148).
- On the OpenAI API, each request only adds to the previous one, and GPT-5.6
  and later share one prompt cache across the sessions of an AgenC home
  (#3182).
- Token estimates for DeepSeek follow the counts DeepSeek reports (#3182).
- DeepSeek sessions on a custom base URL always start with a 64k output
  limit (#3160).
- The NVIDIA NIM picker shows only models NVIDIA still lists, and the
  default is now `nvidia/nemotron-3-super-120b-a12b` (#3121).
- Qwen free-tier exhaustion is reported as a billing problem instead of a
  bad key (#3128).

## Memory

- Memory saves run inside the sandbox with no second approval card (#3179).
- Saving or reading a project memory file no longer shows an approval card,
  and deny and ask rules still apply (#3180).
- Grep and Glob can search the session's memory (#3181).
- Daemon sessions now save memories in the background like direct runs,
  with a short helper run every third eligible turn (#3181).
- A worktree child can write only its own session's memory (#3181).
- Shell commands can no longer write into the session's memory folders
  (#3188).
- Asked to forget something, the agent deletes the memory file and its index
  line with a supported tool (#3188).
- Recall reads the memory of the session's own project, never another
  project's (#3188).
- A background memory save can no longer erase a newer index line (#3188).
- Memory indexes are loaded into the session, so the agent no longer lists
  them first (#3141).

## Sandbox and permissions

- If the sandbox refuses a call you approved, AgenC now asks again before
  running it outside the sandbox instead of doing so silently (#3173).
- Writes to protected paths, such as `.vscode` settings or shell startup
  files, ask a person in every mode and are refused when nobody can answer
  (#3138).
- git branch, add and commit work in the default sandbox, while hooks,
  config and other paths that can run code stay protected (#3172).
- A `.git` that is a symlink stays fully read-only, so the sandbox cannot be
  steered into writing its target (#3178).
- A refused git write explains how to approve that one command (#3147).
- Sandbox refusal notices tell the model how to ask for an escalation, and
  offer it only when the session can grant it (#3176).
- A local server that the sandbox blocks, including one started from Python,
  now gets the same clear notice as Node (#3127).
- Light explains how to launch a local server only after a tool result shows
  a server problem (#3151).
- Remote control stays off unless you enable it in your home or managed
  config, and an agent cannot turn it on (#3153).
- Command wrappers such as `busybox`, `ionice`, `watch`, `chrt` and `taskset`
  no longer get around the shell write rules (#3137).
- A helper agent no longer inherits its parent's fast-mode grant (#3137).
- `persistent_session = false` under `[sandbox]` now takes effect in real
  command turns (#3134).
- You can approve a read-only MCP tool as writing no files, once or for the
  session, instead of it being refused (#3143).
- The task board works under the default sandbox (#3169).
- Monitor, the worktree, workflow and CSV job tools, and request_user_input
  run once inside the sandbox instead of being refused or re-run without it
  (#3170).
- A "for this session" approval for Write or Edit covers only the named tool
  and file (#3150).
- Plan mode allows MultiEdit on the session's plan file again (#3166).
- A parent session can review and settle a child agent's unsettled effects
  with /resolve (#3136).

## TUI

- `/theme` picks the color theme with a live preview and saves it to
  `tui.theme` (#3200).
- The slash picker is a compact list under the prompt. A bare `/` lists the
  built-in commands first, then at most five project skills; other skills
  appear when you type their name (#3199).
- The model list in `/model` and `/providers` searches as you type (#3197).
- The footer shows how much input the prompt cache served and says when
  calls bill at off-peak rates (#3198).
- The welcome screen links the AgenC repository (#3195).
- The full welcome logo shows on narrow terminals (#3126).
- A draft you are typing keeps focus when an approval appears, and Escape
  stops the turn and restores it (#3150).
- Shift+Tab during a turn queues the mode change and shows a notice (#3150).
- Shell mode no longer keeps the `!` in your command, and a failed command
  shows its real error (#3152).
- An unknown model name is marked as unverified, and /settings and /undo
  point to /config and /rewind (#3152).
- /status shows one consistent cost, /resume shows progress at once, and
  /rewind shows correct ages (#3139).
- /rewind offers checkpoints from before an automatic compaction (#3157).
- /rewind restores files that a patch moved, and Restore code works on
  prompts from the live session (#3164).
- In the /plan dashboard, fast typing and pastes no longer lose text or run
  as commands (#3186).
- Home paths show as `~/...` in the transcript, tool rows and file approval
  cards, while commands in approval cards stay exact (#3141, #3179).
- Asked how to undo, the agent explains /rewind and its restore choices,
  with or without Git (#3145).

## Fixes

- The status line and the daemon use the same context window, so long turns
  compact before the provider refuses them (#3132).
- With a small context window, compaction shortens tool results to fit
  instead of ending the turn (#3174).
- After compaction, the agent can read exact tool results, MCP results
  included, back from the session history (#3157).
- A quiet model stream shows a warning instead of being cut off, and a dead
  stream is retried (#3142).
- A stream that pads a tool call with endless whitespace is stopped and
  retried (#3192).
- Tool calls that must run alone no longer overlap when a waiting call is
  cancelled (#3182).
- A session whose turn a restarted daemon continued opens again (#3135).
- Resuming after a daemon restart works when the new daemon gets the old
  PID (#3159).
- The daemon no longer refuses to start when a process exits during its
  startup scan (#3177).
- After an update, AgenC gives the old daemon up to 40 s to stop instead of
  failing the first launch (#3122).
- A Goal is marked finished correctly after a disk-full error (#3133).
- A pasted prompt is routed by its full text, so it can start parallel
  helpers like a typed one (#3130).
- Homebrew installs are told to update with `brew upgrade`, and
  `agenc update` refuses to replace Homebrew's files (#3129).
- Runtime downloads tolerate slow links, and a failed prefetch no longer
  fails `npm install` (#3131).
- The native process broker builds with GCC 15, the compiler on Ubuntu
  26.04 (#3185).

## Security

- The private Node.js runtime AgenC ships moves to Node.js 26.12.1, the
  October 2026 security release, and the installers check the installed
  runtime against the release manifest (#3193).
- undici moves to 8.12.3, so a hostile HTTPS server can no longer crash
  AgenC by renegotiating TLS during WebFetch, proxy, mTLS or Qwen requests
  (#3194).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.12`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

New sessions now start in Light mode. To keep the standard mode, set
`light_mode = false` at the top of `~/.agenc/config.toml`, or start AgenC
with `--standard`.

Remote control is now off until you set `enabled = true` under
`[remote_control]` in `~/.agenc/config.toml` yourself and restart the daemon.

If you route AgenC through a proxy with `NO_PROXY`, check that list: with
the new undici, a `*` anywhere in it skips the proxy for every host, and
`*.example.com` no longer matches `example.com` itself.

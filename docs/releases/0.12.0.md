# AgenC 0.12.0

AgenC 0.12.0 introduces a redesigned monochrome terminal workbench and makes
delegated-agent workflows reliable under sandbox admission.

## Terminal workbench

- The default dark TUI now uses deliberate black-and-white chrome across the
  title bar, workspace and agent rails, transcript, composer, footer, and
  selection surfaces.
- Cold start carries the AgenC mark, runtime version, and model more clearly,
  with a cleaner welcome layout and less transcript metadata noise.
- Transcript alignment, composer spacing, slash and permission pickers,
  project-tree labels, and agent status presentation are more consistent at
  compact and full terminal sizes.

## Delegation and isolation

- Collaboration controls such as `spawn_agent`, `assign_task`, and
  `send_message` are admitted as orchestration operations instead of being
  mistaken for direct workspace writes. Child filesystem access remains
  enforced by the child sandbox and worktree manager.
- The Linux release gate now exercises the production broker, packaged
  launcher, bubblewrap, and real kernel isolation end to end, including
  namespace separation, network denial, read-only mounts, descendant cleanup,
  and AppArmor cleanup.
- Capability-specific PowerShell, Neovim, macOS, Windows, and Linux-kernel
  coverage runs in dedicated native lanes. The authoritative suite rejects
  skipped tests instead of treating them as passing evidence.

## Distribution

- All five native targets remain self-contained on the pinned Node.js 26.5.0
  runtime, with Linux artifacts built against the Rocky 8 / glibc 2.28 floor.
- The Homebrew formula installs the complete private-Node runtime and uses
  current architecture-selecting URL and checksum syntax.

There are no breaking configuration, daemon-protocol, or SDK changes in this
release. The SDK remains independently versioned at `0.3.0`.

## Upgrading

```sh
agenc update                              # standalone installs
npm install -g @tetsuo-ai/agenc@latest   # npm installs
brew upgrade agenc                       # Homebrew installs
```

Restart an already-running daemon after updating:
`agenc daemon restart`.

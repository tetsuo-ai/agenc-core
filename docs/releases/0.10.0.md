# AgenC 0.10.0

Adaptive swarm mode now turns qualifying parallel routes into real delegation
attempts instead of relying on model guidance alone.

## Swarm execution

- A parallel root turn force-selects `spawn_agent` for its first provider
  request, so the model must attempt at least one bounded worker assignment
  before starting local investigation or implementation.
- The exact-turn claim is one-shot. Provider reconnects reuse the same request,
  while tool-result and mailbox follow-ups do not recursively spawn replacement
  workers.
- Multi-domain review or research lists can route in parallel without requiring
  users to add special “use multiple agents” wording.

## Safety and control

- Sequential work, coupled tasks, explicit no-delegation requests, and child
  agents do not force a spawn.
- Plan mode remains non-mutating. Missing `spawn_agent` availability is
  reported honestly instead of pretending workers launched.
- Spawn approval, sandbox, capacity, admission, budget, and worktree
  integration controls are unchanged.

The routing receipt advances to `agenc.swarm.route.v2`. There are no breaking
configuration or API changes.

## Upgrading

```sh
agenc update                              # standalone installs
npm install -g @tetsuo-ai/agenc@latest   # npm installs
```

Restart an already-running daemon after updating:
`agenc daemon restart`.

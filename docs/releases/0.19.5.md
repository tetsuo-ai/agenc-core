# AgenC 0.19.5

AgenC 0.19.5 adds Venice AI as a provider, shows your git status above the
input, and fixes problems found by testing the TUI the way people use it.

## New

- The TUI shows the current git branch above the input, with the number of
  changed files and how far the branch is ahead of or behind its upstream. It
  updates after tool calls, when the terminal regains focus and every 30
  seconds, and it stays hidden outside a git repository. Set
  `tui.gitStatusEnabled = false` to hide it.
- Venice AI is a built-in provider. Set `VENICE_API_KEY`, then choose a model
  with `--model venice:<model>` or `/model`. AgenC lists only Venice models
  that can call tools, and it turns off Venice's own system prompt and web
  search so your session's instructions and tools apply.

## Fixes

- Pressing Enter right after a paste no longer loses the prompt.
- Pasted Windows text keeps single line breaks instead of doubling them.
- A multi-line paste from a terminal that strips paste markers stays one
  draft instead of sending each line as a prompt.
- In a short terminal, the approval card keeps every choice and the Esc hint
  visible.
- When a model's answer is cut off and retried, the cut-off text no longer
  runs into the new answer.
- An edit to a file the model has not read is refused before you are asked to
  approve it, and the message names the file to read first.
- Recalled memories are no longer attached again after every tool call. This
  cut input by 18 to 27 percent on tasks that use memory.
- On Linux, `[sandbox.network] allowLocalBinding = true` now lets a command
  run a local server on loopback inside the sandbox. Each command has its own
  network, so start and test the server in the same command. With the
  default setting, a blocked server gets a one-line explanation instead of a
  bare EPERM.
- Unknown slash commands point to `/help`, and `agenc -p` with bypass flags in
  a folder you have not trusted says how to continue.
- When the AgenC daemon cannot start, the TUI now shows why and how to start
  it, and pressing Enter explains the problem instead of doing nothing. Your
  prompt stays in the input, and once the daemon runs the next Enter works.
- `/swarm on` and `/swarm off` keep the effort you set with `/effort`.
- Pressing Esc while helpers run shows an interruption, not a timeout, and a
  reply cut off by the output limit no longer reports an out-of-order tool
  result.
- Resuming a long session after a daemon restart is faster: restoring a
  session with about 94,000 entries took 3.6 s of parsing instead of 9.3 s.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.5`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

# AgenC 0.9.4

First-run setup now gets users to working model access directly, without
requiring them to discover or type slash commands.

## Onboarding

### Account access is built into first run

- **Sign in or create an AgenC account** launches the hosted-model account
  flow from the wizard. Free accounts are placed on the hosted free-model
  catalog automatically.
- **Sign in with X / xAI** launches the Grok subscription flow for eligible X
  or xAI accounts, including a visible device-code fallback when a browser
  callback is unavailable.
- Provider API keys, local Ollama or LM Studio access, and **Configure later**
  remain explicit choices in the same model-access step.

### The wizard is actionable

- First-run setup uses a dedicated input composer with clear choices and
  accepts the displayed default with Enter.
- Browser URLs and device codes remain visible while authentication is
  pending.
- Provider keys are verified before an explicit yes/no save decision.
- Signed-in free accounts recognize their hosted `:free` route as ready
  instead of incorrectly asking for a paid key.

## Distribution reliability

- The installer promotion workflow now distinguishes a genuinely absent
  `installer-stable` branch from authentication, network, or malformed API
  failures, so first promotion remains resumable without failing open.

There are no breaking configuration or API changes and no migration is
required.

## Upgrading

```sh
agenc update                              # standalone installs
npm install -g @tetsuo-ai/agenc@latest   # npm installs
```

Restart an already-running daemon after updating:
`agenc daemon restart`.

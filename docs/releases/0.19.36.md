# AgenC 0.19.36

AgenC 0.19.36 makes Light on OpenAI models write shorter commands: the model sees `exec_command` with two fields and
stops repeating the workspace path on every call. This is the default on the OpenAI API and with ChatGPT sign-in.
QwenCloud gains Qwen4 Max. Gemini gets fewer empty answers, fuller steps on Flash and a cheaper Gemini 3.1 Pro.

## OpenAI

- Light sessions of the `openai` provider show `exec_command` to the model with two fields, `cmd` and `timeoutMs`.
  GPT models write every field they are shown on every call, so each command carried the absolute workspace path and
  `background: false`, about half of the characters of its arguments. On GPT-6.1 Terra and Sol this cut the output
  tokens by 11.8% and the task time by 6.9% in our measurement, with the same number of tasks solved (#3581).
- A command runs in the workspace root. `workdir`, `background` and the other fields are named in the tool's
  description and still accepted; the model loads them when a command needs one (#3581).
- `AGENC_OPENAI_LIGHT_OUTPUT=off` turns it off and sends the 0.19.35 requests. Other modes and other providers are
  unchanged (#3581).
- New opt-in: `AGENC_OPENAI_LIGHT_OUTPUT=no-summary` stops asking for a reasoning summary in Light sessions unless
  `reasoning_summary` is configured. The encrypted reasoning is still replayed (#3581).

## QwenCloud

- Qwen4 Max (`qwen4-max`) is a known model on `qwen` (Pay-As-You-Go) and `qwen-token-plan`: 1,000,000 tokens of
  context, 262,144 output tokens, images, tools and parallel tool calls. It is listed first in the model picker on
  both routes (#3582).
- Its effort levels are none, low, high (default) and xhigh. The model has no medium level, so medium runs as high
  (#3582).
- The cost display knows its Pay-As-You-Go price: $1.50 per million input tokens, $4.50 per million output tokens,
  $0.075 per million cached tokens. The Token Plan shows "plan" with no dollar amount, because QwenCloud publishes no
  Credits rate for it (#3582).
- Qwen3.8 Max stays the default model on both routes. `qwen4-max-preview` is unchanged: Token Plan only, retired by
  QwenCloud on November 25, 2026 (#3582).

## Gemini

- A workspace tool result now reaches Gemini under an `AGENC_DATA` key in the function response instead of between
  two marker lines. On `gemini-3.8-flash` those lines led to empty or broken answers after a step of several small
  reads; in replays of recorded requests they fell from 56 of 90 to 2 of 90 (#3583).
- The Light instructions of the native Gemini provider ask for fuller steps: every file the task needs in one
  response, and independent commands together. On `gemini-3.8-flash` a task took 12% fewer model calls, with the same
  44 of 44 tasks solved and no clear change in time or cost. `gemini-3.1-pro-preview` keeps the short sentence
  (#3583).
- `gemini-3.1-pro-preview` sessions keep the system instruction and the tool list in an explicit Google cache, because
  Google's implicit cache skips requests under about 8,200 prompt tokens on this model. The cached share of the input
  rose from 19% to 43% in our measurement. Google bills storage for the cache (about $0.001 per 10 minutes) and its
  creation as input; neither is part of the session's token accounting (#3583).
- `GEMINI_CACHED_CONTENT=off` turns the cache off; a cache of your own named there is used instead. The cache is used
  on Google's own endpoint only, not on Vertex or a custom `GEMINI_BASE_URL`. If Google refuses a request that names
  the cache, AgenC sends it again without it and stops caching for that session head (#3583).

## Shell

- With approvals and the sandbox both bypassed, a shell command may move a whole `.git` directory to a `.git` path
  that does not exist yet inside the workspace, for example to put an application's repository back after its
  directory was replaced. Both paths must be real paths without symlinks, outside protected roots. Deleting `.git`,
  writing into it and replacing an existing one stay refused, and approval bypass alone does not allow it (#3585).

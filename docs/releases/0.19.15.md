# AgenC 0.19.15

AgenC 0.19.15 fixes headless prompts on Windows. AgenC accounts no longer
provide models, provider keys or model credits. Use your own provider key,
a provider sign-in or a local model. User-visible messages use plain
punctuation in place of em dashes.

## Windows

- Headless prompts with `agenc -p` no longer fail with an `EPERM` directory
  sync error before the provider call. Session history and display artifacts
  use the same Windows handling. File writes are still flushed, and real
  I/O errors still stop the operation (#3248).

## Models and accounts

- An AgenC account no longer supplies models, provider keys, proxy access
  or model credits. Configure your provider in `/providers`. OpenRouter
  free models need your own OpenRouter key, just like paid models (#3251).
- Existing `[auth.managed_keys]` and `[auth.managedKeys]` settings load but
  are ignored, with a notice. `AGENC_AUTH_MANAGED_KEYS_ENABLED` no longer
  enables account-provided models (#3251).
- AgenC sign-in still supports account identity, marketplace access,
  remote pairing and desktop sync. Provider sign-ins, including ChatGPT
  and X / xAI, continue to use your own provider account (#3251).

## Messages

- CLI output, menus, status messages and diagnostics use commas, colons,
  periods or parentheses in place of em dashes. A guard test checks the
  user-visible strings covered by this change (#3249).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.15`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

If you used models through your AgenC account, open `/providers` and connect
your own provider before starting another model turn. For OpenRouter, set
`OPENROUTER_API_KEY` or add your key in `/providers`.

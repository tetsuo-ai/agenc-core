# AgenC 0.19.18

AgenC 0.19.18 adds a manual web search setting, completes the Kimi cache
pricing and usage follow-up, and reduces repeated completion checks.
It also remembers when you stop a response, corrects Claude model names
on Amazon Bedrock, and fixes native Windows persistence and source builds
with the .NET Framework compiler.

## Web search

- Open `/model` and select the `Web search` row to switch between `Auto`
  and `On`. The setting also appears on model pages in `/providers` and
  is saved for later sessions. Auto is the default and keeps the existing
  tool discovery behavior (#3287).
- On makes WebSearch and web_fetch available from the first request and
  adds one short prompt instruction to use them for web work. A `Web`
  marker appears in the footer. In the measured DeepSeek requests, On
  added about 279 input tokens per request in Light and 263 in standard
  mode. Token counts vary by provider; searches and page reads can add
  further usage (#3287).
- On enables DeepSeek Search for DeepSeek sessions, including proxy
  routes. An explicit `AGENC_DEEPSEEK_WEB_SEARCH` override keeps priority.
  `AGENC_WEB_SEARCH=auto|on` overrides the saved setting (#3287).

## Kimi caching and usage

- Native Kimi requests use a stable session cache routing key. K3 requests
  accept five-minute or one-hour implicit cache TTLs through
  `AGENC_KIMI_CACHE_TTL`. The first write fixes the TTL; later cache hits
  renew that original TTL (#3286).
- Usage accounting reads the actual cache write tier from responses and
  includes published model prices and one-hour write rates. Cache hits,
  writes and uncached input are counted without duplication (#3286).
- The follow-up records 72 passing task runs across all six native models,
  with additional stress results and preserved failures. Unsupported
  combinations of tools and structured output remain guarded; use tool
  steps first and request the final schema separately (#3286).
- Native Kimi retains its retained-data indicator. Enterprise ZDR requires
  Moonshot approval. OpenRouter routes use their own endpoint eligibility
  and request-level ZDR controls (#3286).

## Completion checks

- Completion reviews reuse current evidence and group requirements into
  at most five short evidence lines. A narrow literal-file write and
  complete read-back can finish without an extra model call when the
  requested content and final answer match (#3267).
- Verification is limited to three checklist requests and six additional
  model samples, including tool continuations. Each gated request uses at
  most 8,192 output tokens and respects lower configured limits. Exhausted
  checks report incomplete verification (#3267).
- In three measured tasks, completion overhead fell from nine calls to
  two and from 32,296 tokens to 6,188, with all three artifacts passing
  before and after. These are small task samples, not a general speed
  guarantee (#3267).

## Interrupted responses

- When you stop a response, AgenC records that you cancelled it. Your next
  message no longer leaves the stopped request looking unanswered to the
  model. The note stays in the conversation when you resume the session
  and also applies to Light and sub-agent sessions (#3292).

## Amazon Bedrock

- Claude model shortcuts such as `sonnet`, `opus` and `haiku` now send
  correctly spelled Claude model IDs to Amazon Bedrock. The old names
  could make these requests fail. Sessions using a full model ID or ARN
  were not affected (#3288).

## Windows

- Persisted file-history paths use native separators. SQLite supports
  extended Windows paths and writable handles where file synchronization
  requires them. Directory handling avoids unsupported Windows permission
  operations while retaining identity checks (#3265).
- Source builds can use the in-box .NET Framework compiler for the Windows
  process broker. Modern Roslyn compiler options remain available, and
  compiler failures retain their diagnostics (#3265).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.18`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.

# AgenC 0.19.14

AgenC 0.19.14 puts `agenc` on your PATH when you install it on Windows. It
turns on zero data retention for OpenRouter by default and shows a ZDR badge
in the status line. /usage shows the balances and usage of your providers.
OpenRouter models can make parallel tool calls, and Claude and Gemini through
OpenRouter use prompt caching. Local Ollama runs models at a context window
AgenC plans for, lists your installed models, and keeps gpt-oss's reasoning
inside a tool loop.

## Windows

- The installer adds AgenC to your user PATH, so a new terminal finds `agenc`
  right away. Set `AGENC_NO_MODIFY_PATH=1` to opt out. It no longer suggests a
  `setx` command, which could merge the system PATH into yours and cut it at
  1,024 characters (#3245).

## Privacy and the status line

- With your own OpenRouter key, every request asks for zero data retention
  (ZDR) unless you set `zero_data_retention = false` under
  `[providers.openrouter]` (#3240).
- Sub-agents, reviewers and WebSearch keep the ZDR setting of the session
  (#3240).
- `/model` and `/providers` mark OpenRouter models with no ZDR endpoint as
  `no ZDR`, and a refused request says so instead of pointing at the base URL
  (#3240).
- The status line shows `ZDR` in green when the provider keeps nothing, in
  red when data may be kept, and a dim `ZDR?` when AgenC cannot know, as for
  an OpenAI-compatible server that may forward to a cloud API. `/status`
  explains why (#3240).
- On narrow terminals the status line uses short forms first, then a second
  row, so it keeps its facts (#3240).

## Usage

- `/usage` adds a Providers section with the balance or usage that Ollama
  Cloud, OpenRouter, DeepSeek, Venice, Kimi and abliteration.ai report for
  your key. `/usage <provider>` shows one in detail (#3239).
- Each lookup has a 5 second limit, and a key only goes to the endpoint the
  provider's chat requests use (#3239).

## Providers

- OpenRouter models other than GPT and DeepSeek can make parallel tool calls.
  AgenC used to send `parallel_tool_calls: false` to them (#3228).
- Claude and Gemini through OpenRouter use prompt caching, so later calls
  read the prompt from cache at a lower price (#3230).
- abliteration.ai requests carry the session's cache key in the
  `x-abliteration-session-id` header as well as in the body, as
  abliteration.ai documents (#3242).
- The first Ollama Cloud request of a turn no longer waits for a second read
  of the model's details (#3237).
- A Venice key is checked against an endpoint that rejects a wrong key, so
  `/providers` no longer accepts a made-up key (#3232).
- Models that number their tool calls per response, as some Venice, Kimi and
  Gemini models do, no longer stop the session on a later tool turn (#3220).
- OpenRouter vision models now see the images tools return, such as
  screenshots (#3222).

## Local Ollama

- AgenC runs local models at a 32,768 token window, or the model's trained
  length if smaller, and sends it as `num_ctx`. Before, Ollama could run a
  model at 4,096 tokens and silently drop the start of the session (#3231).
- `/model` and `/providers` list the models installed on your Ollama server,
  with vision, thinking and no-tools tags when the server reports them
  (#3233).
- `/effort` sets gpt-oss's thinking level (low, medium or high) (#3234).
- A thinking model keeps its reasoning between the steps of a tool loop. In
  our tests gpt-oss:20b solved 18 of 32 tasks instead of 10 (#3236).
- A busy Ollama server or a passing server error is retried instead of ending
  the turn. A model Ollama cannot load still ends the turn at once with
  Ollama's message (#3227).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.14`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

OpenRouter: zero data retention is now on by default. A model with no ZDR
endpoint (about 80 of the 298 models in AgenC's OpenRouter list, including
`google/gemini-2.5-flash`) fails every request until you pick another model
or set `zero_data_retention = false` under `[providers.openrouter]` in
`~/.agenc/config.toml`.

Local Ollama: AgenC now always sends `num_ctx` (32,768 tokens, or the
model's trained length if smaller). This overrides `OLLAMA_CONTEXT_LENGTH`
and the larger default Ollama picks with 48 GiB or more of GPU memory. To run
a local model at another window, set `context_window_tokens = 65536` (or
your value) under `[providers.ollama]` in `~/.agenc/config.toml`.

Windows: `agenc update` does not change your PATH. If a new terminal does not
find `agenc`, run the installer once
(`iwr -useb https://get.agenc.ag/install.ps1 | iex`); it adds the entry.

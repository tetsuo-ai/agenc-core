# AgenC 0.19.17

AgenC 0.19.17 adds Kimi K3.1 Pro and Kimi K3.1 Pro Highspeed.
It starts the daemon before loading old session snapshots. On macOS,
it also gives the daemon's Node executable a stable path and removes unused
runtime versions after an update. Model transport recovery and failed-turn
reporting are more consistent. The abliteration provider adds Abliterated Large
Flash.

## Kimi K3.1

- `kimi:kimi-k3.1-pro` and `kimi:kimi-k3.1-pro-highspeed` appear in the model
  picker. Both support image input and a 1,048,576-token context (#3264).
- Thinking stays on, with low, high and max reasoning effort. Requests use
  K3-family controls and preserve reasoning content during tool conversations
  (#3264).
- Moonshot's automatic prefix caching keeps shared prompt content together.
  Usage parsing includes cache hits and reported cache writes. K3.1 prices
  remain unpriced until verified rates are available (#3264).

## Daemon startup

- The daemon accepts connections while old session snapshots load in the
  background, four sessions at a time. New sessions can start immediately.
  Requests for an old session wait for that session's recovery (#3261).
- Startup shows `Starting AgenC...` after one second. A request waiting for
  recovery shows `Reopening N sessions...` and cancels its wait after two
  minutes. Journal validation and cancellation repair still finish before
  the daemon becomes ready (#3261).
- Retention counts stored bytes without loading snapshot text. Startup avoids
  a full database rewrite, and recovery summaries no longer duplicate full
  transcripts (#3261).

## macOS runtime updates

- Standalone and npm installations use `<AGENC_HOME>/bin/agenc-node` for the
  verified Node executable. Keeping its path and signing identity stable is
  intended to preserve macOS folder permissions across updates. The first
  migration can still ask for access; repeated-update dialog behavior has not
  been manually verified (#3258).
- After activation, cleanup keeps the current runtime, the previous runtime,
  and runtimes used by running processes. Incomplete process checks or an
  update in progress defer cleanup. Interrupted activation and cleanup can
  recover on a later attempt (#3258).
- Pinning an earlier version still works. Linux, Windows, development
  checkouts, and Homebrew retain their existing executable paths (#3258).

## Interrupted turns

- An incomplete compatible tool-call stream is treated as an interrupted
  connection. Retries respect the remaining run deadline and a bounded number
  of slow recovery attempts. A request that may have dispatched tools is
  stopped rather than replayed (#3262).
- Failed one-shot turns keep their failure status. Structured results retain
  transport category, elapsed time and remaining deadline where available.
  Disconnect diagnostics report recorded daemon exit and memory evidence
  without claiming a cause that was not observed (#3262).
- Shell tools refuse recognized literal kill commands when process checks
  confirm they would hit AgenC or an ancestor. CLI process titles also avoid
  exposing prompt text where the operating system supports it. This check is
  limited to recognized commands and available process information (#3262).

## Abliterated Large Flash

- `abliteration:abliterated-model-large-flash` appears in `/model` and
  `/providers`, including when live discovery is unavailable. It supports
  image input, a 1,048,576-token context and up to 262,144 output tokens
  (#3263).
- Reasoning choices are off, low, high and max, with high as the default.
  In Light, the model uses DeepSeek's batch Edit and task limits. Ordinary
  calls reserve 64,000 output tokens; explicit settings can use the model's
  full output limit (#3263).
- Requests keep abliteration's session cache fields. The provider default
  remains Large v2 (#3263).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.17`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.
On a Mac, allow folder access if the first launch from the stable Node path
asks for it so AgenC can reopen sessions in those folders.

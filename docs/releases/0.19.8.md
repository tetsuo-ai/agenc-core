# AgenC 0.19.8

AgenC 0.19.8 starts a TUI session on Windows in the default mode, and fixes
two small problems found while testing 0.19.7.

## Windows

- AgenC has no sandbox on Windows yet, so the default mode refused to start a
  session there (`sandbox_required_unavailable`). Now the TUI asks once,
  before the first session, whether to continue without a sandbox.
- Continue saves `sandbox_mode = "danger-full-access"` in your `config.toml`.
  Approvals still apply, so AgenC asks before each command and file edit.
  Quit saves nothing, and the question comes back on the next start. To
  answer again, run `agenc config unset sandbox_mode`.
- The question never replaces a sandbox mode that you, a profile or a
  repository chose.
- A run without a terminal (`agenc -p`) never asks. Until you have answered,
  it refuses as before. It cannot answer approvals either, so pass
  `--bypass-approvals` for unattended runs.
- The trust card now says when the sandbox is off for the run. On a host
  without a sandbox, `--bypass-approvals` also says so in the TUI footer.

## Fixes

- The bundled `simplify` skill now says it is only for when you ask to review
  or clean up code. In one 0.19.7 test run the model started it on its own
  after its fix already passed, and the run took twice as long. `/simplify`
  and review requests work as before.
- An error that stops a session from starting no longer ends with two
  periods.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.8`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

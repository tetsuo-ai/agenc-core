# AgenC 0.19.22

AgenC 0.19.22 adds GPT-6.1 Terra and Gemini 4 Argon. OpenAI tools with
optional fields now keep those fields optional, and Gemini tool calls go back
with their thought signatures and call ids.

## GPT-6.1 Terra

- AgenC knows GPT-6.1 Terra (`gpt-6.1-terra`): its context and output limits,
  reasoning efforts from none to max with medium as the default, its prices
  (including the long-context rate above 272,000 input tokens and the fast
  tier) and the OpenRouter rows `openai/gpt-6.1-terra` and
  `openai/gpt-6.1-terra-pro`. Before, it ran as an unknown model without
  limits and was charged at the conservative price ceiling (#3322).
- Terra keeps its own reasoning summary default when AgenC sends a
  conversation back, as GPT-6 Luna does (#3322).

## OpenAI tools

- On OpenAI's platform API, a tool with optional fields now goes out with
  `strict: false`. Before, OpenAI turned every optional field into a required
  one, so models filled in guesses such as a working folder or a timeout on
  every call. Tools whose fields are all required are sent as before, and the
  ChatGPT subscription backend keeps its request shape (#3328).

## Gemini

- Gemini 4 Argon (`gemini-4-argon`) is available with the low, medium and high
  thinking levels (medium by default) and its prices (#3327).
- Prices that Google announced to change on a set date switch on that date:
  Argon on 2026-12-01; 3.8 Flash, 3.6 Flash and Robotics ER 2 on 2027-01-01
  (#3327).
- `gemini-3.7-flash` and `gemini-3.5-flash` are deprecated by Google. They are
  hidden from the model pickers, saved settings that name them keep working,
  and 3.5 Flash is priced at the 3.6 Flash rate Google now bills (#3327).
- Requests to the Gemini Developer API and to custom base URLs send
  `store: false`, so new paid projects do not keep them in their AI Studio
  logs. Vertex requests are unchanged (#3327).
- An HTTP 402 from Gemini now says that the Prepay credit balance is used up
  and how to add credits (#3327).
- A Gemini chat model that Google lists but AgenC does not register yet can be
  selected and run, with the window and output limit Google lists and no price
  (#3327).
- Gemini tool calls go back in the form Google documents. Each call keeps its
  own thought signature, also after a model fallback, a resumed session, a
  compaction or a redacted record. Function responses carry the call id, and
  the results of one step travel together. Before, such turns could fail with
  HTTP 400 "Function call is missing a thought_signature" (#3330).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.22`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.

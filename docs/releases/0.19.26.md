# AgenC 0.19.26

AgenC 0.19.26 runs a skill with the model, effort and tool approvals its file declares. Tools in a sub-agent
now use that sub-agent's own provider, keys and connection. `agenc -p` cost includes tool fees, Ollama Cloud
web fetch follows your web_fetch rules, and updates restart the daemon one at a time. A refused shell command
ends the turn with its reason at every exit, code mode works in installed runtimes again, and QwenCloud Token
Plan models run much better.

## Skills

- `$name` and `/name` run the turn with the skill's frontmatter `model`, `effort` and `allowed-tools`. The
  next turn goes back to the session's settings. Repo skills still have these settings removed. The settings
  also hold when the turn resumes after a crash (after the skill and the policy are checked again), during
  compaction in that turn, and for a skill sent as the first prompt before the session is ready (#3366).
- Built-in skills can only pre-approve file tools. Shell, process and MCP grants are dropped, and
  `/ledger-wallet-cli` no longer pre-approves shell commands (#3366).
- A managed-only policy applies at once, even in the middle of a skill turn (#3366).
- With a daemon older than the TUI, a skill runs without its settings, and the TUI says to restart the
  daemon (#3366).

## Tools and cost

- web_fetch prompt extraction, WebSearch, Grok native search, XSearch and the Imagine tools use the session
  that called them: a sub-agent's own provider, model, key, sign-in and connection settings, never its
  parent's. Keys added or rotated during a session apply on the next call (#3363).
- An OpenAI or MiniMax session on an API key now makes images and video with its own key and URL. A ChatGPT
  sign-in still never reaches the media APIs (#3363).
- `agenc -p --output-format json` now counts tool fees, such as DeepSeek search and fetch, and the model calls
  that tools make in `tokenUsage.costUsd` (#3363).
- Ollama Cloud web fetch follows the same rule as DeepSeek's: it is used only in "never asks" mode with no
  web_fetch rule, and only for public hosts. Otherwise AgenC fetches the page itself and checks every
  redirect (#3363).

## Updates

- Daemon restarts after an update run one at a time, so two updates at once end with one daemon on the
  newest version (#3364).
- When an update cannot cancel a pending restart onto a newer build, it says so and leaves the daemon as it
  is, instead of logging the cancel as done (#3364).
- `agenc update --pin <version>` moves the daemon to exactly that version (#3364).
- An update that waits for another restart prints that it is waiting. The TUI tells you when a restart it
  follows fails or is replaced by a newer one (#3364).
- A downgrade to a version older than 0.19.26 does not take the new restart lock, so do not run two updates
  at once while downgrading (#3364).

## Shell and code mode

- When the shell is paused after an unproven process cleanup, a refused command ends the turn with its reason
  at every turn exit, including the step limit, the task budget and a failed model call (#3365).
- Code mode (`AGENC_CODE_MODE=1`) runs scripts in installed runtimes again. In 0.19.25 every script failed with
  "Cannot find module 'quickjs-emscripten'" (#3365).
- A code-mode script's tool calls run only in the turn that started it, and are refused once that turn ends
  (#3365).

## QwenCloud

- Token Plan quota and rate-limit errors are recognized, seven hosted DeepSeek and GLM models are added,
  Qwen3.6 uses context caching, and Qwen3.8 in Light mode gets task limits (#3367).
- Thinking can be turned off (`/effort off`) for Qwen3.8 Max, Qwen3.8 Flash and GLM-5.2 (#3367).
- On qwen3.8-max and qwen3.8-flash, AgenC now beats Pi, Hermes and Qwen Code on solves, tokens and time in our
  race tasks, and solves 18 of 20 held-out tasks, against 10 of 20 before (#3367).

## Elicitation

- In apps that run AgenC in process, an elicitation form that the session withdraws after a field change or a
  validation error now closes (#3362).

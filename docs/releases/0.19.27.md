# AgenC 0.19.27

AgenC 0.19.27 makes interactive Light faster on DeepSeek and GPT models. DeepSeek Light now gets the project's file
names with your first message, so it reads files instead of listing the folder first, and it runs checks instead of
probing versions and git history. On GPT models Light writes the simplest code that meets the request and stops once
its checks pass. AgenC also waits less between model calls.

## Speed

- On Linux, interactive DeepSeek Light gets the file names of the folder you started in with the first message of a
  conversation, so the model reads the files it needs instead of spending its first call on `ls` or `find`. The list
  covers up to 50 names, 3 levels deep (#3371).
- Interactive DeepSeek Light runs checks directly instead of first probing tool versions or git history (#3371).
- On our DeepSeek race tasks this made AgenC 37.5 s faster over 22 runs and used 16% fewer tokens, with every task
  solved (#3371).
- On DeepSeek Flash, AgenC now solves every race task and beats Pi, OpenCode, Hermes and the DeepSeek harness on tokens
  and time: 274.5 s and 415,194 tokens for all 22 runs, against 393.6 s and 1,529,107 tokens for the next fastest,
  OpenCode. Against 0.19.26 that is 30% less time and 25% fewer tokens (#3371).
- Interactive Light on GPT and other non-DeepSeek models writes the simplest code that meets the request, reruns checks
  only after new edits or failures, and stops reworking code once its checks pass. A large change goes in a few patches
  of related files. The new rules use fewer tokens than the old ones. On GPT-6 Luna the effect varied between runs:
  27% to 38% faster than 0.19.26 in three A/B runs, but 10% slower in the release race, close to its run-to-run
  variation (#3371).
- Less waiting between model calls. The code highlighter and Markdown rules load while the session waits, the error-log
  index no longer forces a disk flush during a turn, and npm's update check is off in sandboxes that cannot record it
  (#3371).

## Safety of the file list

- File names are untrusted data: they are sanitized like other workspace text and marked as untrusted for the model
  (#3371).
- The list is left out when the folder is your home folder, `/` or a folder that contains your home folder, when
  listing takes longer than 200 ms, and on macOS and Windows. Folders are read through pinned handles, so a folder
  swapped for a link during the scan is not followed (#3371).
- abliteration.ai's DeepSeek-family models keep their 0.19.26 prompt until they are measured on their own (#3371).

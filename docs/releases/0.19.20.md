# AgenC 0.19.20

AgenC 0.19.20 keeps a finished model response when the connection drops at
the end of the stream, lets a new attempt run after different errors, and
keeps images and documents in context when old text is compacted.

## Finished responses survive a dropped connection

- When a provider that streams Chat Completions, such as DeepSeek, has sent
  the finish reason and the connection then drops, or the HTTP body ends
  before its declared length, AgenC now keeps the finished response. Before,
  the response was discarded and the turn made a new model call (#3316).
- Recovery applies only after the finish reason. A cancelled request, an
  HTTP error or a timeout still fails the call, and tool calls are checked
  as before (#3316).
- When the final usage report was lost, the call's usage is recorded as
  unknown and its budget reservation is kept (#3316).

## Different errors no longer count as repeats

- The repeat guard now ignores process, session and wall time values only in
  the runtime footer at the end of a command result. Errors whose own text
  differs, including different process or session ids, count as different
  failures, so a fourth attempt after three different errors can run.
  Identical failures are still stopped as before (#3316).

## Images and documents kept during compaction

- When old tool results are compacted to save context, results that hold
  images, documents or resource links are now kept whole. Only text-only
  results are replaced by a marker. File recency and marker numbering are
  unchanged (#3316).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.20`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.

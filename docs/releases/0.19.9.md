# AgenC 0.19.9

AgenC 0.19.9 lets a command that the sandbox cuts off from the network run
after one approval, and fixes two small problems found while testing 0.19.8.

## Network commands in the sandbox

- In the default permission mode, when the sandbox blocked a command's network
  access (for example `npm install`, `git clone` or `pip install`), AgenC told
  the model that approval was unavailable. The model then gave up, or asked for
  narrower permissions that still failed. Now it retries once with your
  approval and the command runs.
- `curl -s` and `wget -q` print nothing when the network is blocked, and npm
  on macOS reports `ENOTFOUND`. AgenC now recognizes these as well.
- With `--bypass-approvals`, AgenC tells the model that the retry runs without
  asking, because you turned approvals off.

## Fixes

- The first Browser call opens its page even when the model names tab 1
  before any tab is open. Before, that first call failed and the model had to
  try again.
- On a machine without git, `/status` says "git not installed". Before, it
  showed the raw error "spawn git ENOENT" and flagged it for attention.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.9`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

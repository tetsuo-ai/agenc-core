# AgenC 0.19.31

AgenC 0.19.31 keeps native DeepSeek sessions on their cached prefix across a resume, a restart and a compaction,
keeps the screenshots that a compaction retains, and stops reading requests for helpers inside code or quotes. A
command whose `sandbox_permissions` only means the default now runs instead of being refused, and a turn that made
progress is no longer ended by an earlier repeated call. In the sandbox, a
nested `.git` file or link is handled like a nested repository, and macOS refuses writes to nested repositories as
Linux does (#3418).

## Prompt cache and images

- After a resume, a daemon restart or a fork, an image that left the context keeps the note it had in the live
  session, so the first request keeps the cached prefix. AgenC saves which images a request showed with the
  conversation, as digests without image bytes (#3410).
- Native DeepSeek Light saves its switch to the full core tool list when it happens. A session that stopped during
  the switching turn, or saved a large state, resumes with the list it last sent instead of the compact one
  (#3411).
- After an automatic, manual or partial compaction, the screenshots in the part of the conversation that the
  compaction keeps reach the model as images again, instead of a note that the image was omitted. A restarted
  session still shows the note for those images (#3413).

## Tools

- In /swarm sessions, a request for helpers inside a code span, a fenced block, a quoted line or double quotes no
  longer starts parallel helpers. "Explain `use two helpers` in the docs." now runs as one agent
  (#3414).
- The helper reminder is no longer added when only the words around a code span or quote look like a request, as in
  "Use `--no` sub-agents flag when you run the tests." (#3415).
- A turn no longer ends because a repeated call was refused before the turn made real progress. Refusals of a
  repeated call now count only since the last file change, or the last new command that is not read-only. A call
  repeated without such progress is still refused and then ends the turn (#3417).
- Polling or writing to a session that has already exited now returns its exit status and final output, instead of
  "Unknown process id" (#3417).

## Sandbox

- With `[sandbox.network] allowLocalBinding = true`, a sandboxed command without network access again explains a
  failed lookup, and npm and pip fail at once instead of retrying first (#3412).
- When the model sends `sandbox_permissions` as `"use_default"`, `"none"`, an empty string or `null`, `exec_command`
  and `write_stdin` now run the command in the default sandbox instead of refusing the call. Any other value is
  refused with a message that names it and the three accepted values (#3417).
- On Linux, a nested `.git` file or link that a sandboxed command creates or changes, and that points at files a
  command can write, is moved aside like a nested repository the command creates, and the command fails. Linked
  worktrees, AgenC's own agent worktrees and submodules keep their `.git` (#3416).
- On macOS, a sandboxed command can no longer create a nested `.git` or write a nested repository's hooks or config.
  These need the same approval to run outside the sandbox as `git init` of a nested repository. Writes of refs,
  objects and HEAD inside an existing nested repository still work (#3416).

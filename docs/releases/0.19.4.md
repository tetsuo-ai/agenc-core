# AgenC 0.19.4

AgenC 0.19.4 fixes two problems found while testing 0.19.3.

## Fixes

- The daemon stops and restarts even while macOS waits for you to allow
  folder access. Each update brings a new runtime, so macOS asks again before
  AgenC can reopen sessions kept in Documents, Desktop or Downloads. Until the
  dialog was answered, `agenc daemon restart` and `agenc daemon stop` hung,
  and new sessions got no replies. AgenC now checks those folders in a
  separate process at startup. A session that waits for permission is marked
  unavailable with a note to answer the dialog and resume it, and the daemon
  always exits within a few seconds of a stop.
- `agenc daemon status` no longer says the daemon stopped while its process is
  still running.
- On Linux, the Browser tool no longer picks a snap-packaged browser inside
  AgenC's sandbox, where snaps cannot start. It uses another Chromium-family
  browser when one is installed, and otherwise says to install Google Chrome
  or a non-snap Chromium.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.4`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

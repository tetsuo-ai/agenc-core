# AgenC 0.19.32

AgenC 0.19.32 fixes a 0.19.31 bug that stopped a session from compacting once its core tool list had expanded, so a
long session could not continue after its context filled. It also keeps screenshots in saved conversations, makes
tool calls faster again, and refuses more kinds of repeated failing commands (#3425).

## Compaction

- In 0.19.31, once a session's core tool list expanded (for example after FileRead, tool search or the sandbox
  escalation notice of exec_command), every automatic compaction failed with "active rollout advanced outside the
  compaction admission journal before commit", and the session stopped once its context was full. Sessions compact
  again, on every provider, and a session already stuck this way compacts on its next turn (#3421).
- Session lines written while a compaction runs, such as a Stop from a client, a memory mode change or a helper task
  record, are now written after the compaction ends, so they no longer make it fail (#3421).

## Images

- Screenshots stay in the saved conversation. The secret redaction mistook image data for Solana wallet keys, so after
  a restart or resume the screenshots still in view were dropped and the prompt cache broke at the first image. Only
  complete PNG, JPEG, GIF and WebP image data is exempt from that one rule; text and everything else keep every rule
  (#3423).

## Speed

- Tool calls are faster again. 0.19.31 built a path for every file its nested repository scan listed, twice per call.
  In a replay of a race task, a FileRead in a batch of 12 took 116 ms instead of 140 ms on 0.19.31 (median) (#3424).
- A sandboxed shell command now runs 3 workspace scans instead of 5. In a workspace with about 1,000 node_modules
  folders, the overhead per command fell from 13.6 ms to 10.5 ms. What the scans find is unchanged (#3424).

## Repeated calls and helpers

- A failing command repeated with other commands in between is now refused like a direct repeat. A file change, a
  success of the call or a different error still starts the count again (#3422).
- Repeated sandbox-blocked failures that differ only in their wall time now count as repeats: a blocked server start
  stops after 3 runs instead of 16 (#3422).
- An inch mark such as 5" no longer hides a later request for helpers (#3422).

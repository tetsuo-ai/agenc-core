# AgenC 0.19.13

AgenC 0.19.13 adds abliteration.ai as a built-in provider, and `agenc update`
now finishes on slow connections. `agenc -c` reopens your own conversation
again, a local Ollama runs models that Ollama Cloud also lists, and Venice
rate limits wait for the right window.

## abliteration.ai

- abliteration.ai is a built-in provider. Pick it with
  `agenc --provider abliteration`, `/provider abliteration` or the
  `/providers` screen (#3214).
- Set `ABLIT_KEY`, the key name abliteration.ai documents, or
  `ABLITERATION_API_KEY`, or save a key in `/providers`. When both variables
  are set, `ABLIT_KEY` wins (#3214).
- The default model is `abliterated-model-large-v2`, with a 1M token context.
  `abliterated-model`, which also reads images, and `abliterated-model-large`
  are available too (#3214).
- AgenC runs Large v2 at high effort. `/effort` lists only the modes a model
  runs: low, high and max on Large v2 (#3214).
- Each request carries the session's prompt cache key, and session costs
  count cached input at its lower price (#3214).
- An empty balance is reported as a billing error, and a request blocked by a
  project policy ends the turn with a message that names the request ID
  (#3214).
- `ABLITERATION_BASE_URL` replaces the default endpoint,
  `https://api.abliteration.ai/v1` (#3214).

## Updates

- Each download that `agenc update` makes has its own time limit, which grows
  with the file size, so an update finishes on a slow link as long as data
  keeps arriving (#3215).
- A download that receives no data for 30 seconds stops with one line that
  names it. Nothing is installed after a stopped download, so running
  `agenc update` again is safe (#3215).
- On a terminal, the runtime and GitHub CLI downloads show percent, size and
  rate (#3215).

## Fixes

- `agenc -c` continues your own last conversation. After a few turns it could
  pick a background agent's session, such as a memory save, and stop with
  "not a top-level interactive session" (#3216).
- A local Ollama model whose tag Ollama Cloud also lists, such as
  `gpt-oss:20b`, runs on your own server when you pick it with the `ollama`
  provider. A tag with no provider still selects Ollama Cloud (#3217).
- On a Venice rate limit, AgenC waits for the limit window to reset. It used
  to read Venice's reset times as seconds instead of milliseconds and report a
  wait of millions of seconds (#3219).
- Release builds accept GitHub's newest Windows Server 2025 runner image
  (#3221).

## Security

- AgenC redacts abliteration.ai keys (`ak_...`) wherever it redacts secrets,
  and any value saved under `ABLIT_KEY` or `ABLITERATION_API_KEY`, such as in
  session files (#3214).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.13`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

The new download limits apply from 0.19.13 on, because the installed version
runs the update. If you are on 0.19.12 or older and `agenc update` stops with
"body timed out" on a slow connection, update once with the installer
(`curl -fsSL https://get.agenc.ag/install.sh | sh` on macOS and Linux,
`iwr -useb https://get.agenc.ag/install.ps1 | iex` on Windows) or with npm.

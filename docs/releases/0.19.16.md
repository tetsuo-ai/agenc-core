# AgenC 0.19.16

AgenC 0.19.16 loads OpenRouter's live model catalog and improves compatibility
with its models. The catalog listed 468 models on October 23, up from the 298
in the bundled list. Models without agent tools are included too.

## OpenRouter models

- `/model` and `/providers` use the live catalog for model names, capabilities,
  context limits and token prices. The menus read cached data and refresh in
  the background. The cache lasts one hour. If the live catalog is unavailable,
  AgenC uses the bundled list and shows a fallback notice (#3253).
- Models without tool support remain selectable and show a note about agent
  tools. Catalog entries also identify vision, thinking and free models.
  Saved model selections stay pinned. Catalog prices are estimates; costs
  reported by the provider take precedence (#3253).

## OpenRouter compatibility

- Reasoning from an earlier response is replayed on the same model and provider
  route when the next request needs it. Structured reasoning takes precedence
  over the plain reasoning field (#3257).
- Requests require an endpoint that supports their parameters. Zero data
  retention remains enabled by default. AgenC omits the optional parallel-tool
  control from OpenRouter requests; native parallel tool calls
  remain supported (#3257).
- Ordinary output reservations are capped at 32,000 tokens and the model's
  limit. Explicit output settings, larger recovery ceilings and the existing
  DeepSeek behavior are preserved. Small context windows use a proportional
  safety buffer instead of reserving a fixed 1,024 tokens (#3257).

These changes follow a live sweep of 291 models. A model appearing in the
catalog does not guarantee reliable agent tools. Some endpoints still return
tool-shaped text, empty answers or upstream errors. AgenC does not execute
tool-shaped text or turn hidden reasoning into an answer.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.16`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

OpenRouter models, including free models, need your own OpenRouter key.
Set `OPENROUTER_API_KEY` or add your key in `/providers`.

# AgenC 0.11.1

AgenC 0.11.1 is the first published Node.js 26 release. It moves the release
runtime to Node.js 26.5.0 (module ABI 147, Node-API 10) and makes standalone
installations self-contained.

The `agenc-v0.11.0` source tag did not publish runtime, installer, npm, or
Homebrew artifacts: its hosted Rocky inventory gate detected signed package
content that had advanced since the previous reviewed inventory and stopped
before Linux compilation. This patch refreshes both architecture-specific
inventory digests from the pinned Rocky 8 image and signed RPM set. The source
tag remains unchanged.

## Self-contained standalone runtime

- Every modern runtime artifact carries the exact reviewed Node executable,
  Node license, and a hash-bound runtime identity next to AgenC.
- Linux artifacts also carry the required `libatomic.so.1` compatibility
  library and GCC runtime attribution. The generated wrapper uses only that
  private library directory.
- The macOS/Linux and Windows installers can securely bootstrap with the exact
  checksum-pinned Node distribution when the host has no compatible Node.
  Bootstrap state is temporary; the installed wrapper always targets Node
  inside the content-addressed runtime tree.
- Homebrew no longer needs a host-Node dependency. Its formula installs the
  complete macOS runtime artifact under `libexec`.

## Release and update safety

- All five native targets, Docker images, npm, headers, import libraries, and
  native ABI checks are pinned to Node 26.5.0.
- Official Linux artifacts build on Rocky 8 and reject symbols above glibc
  2.28, GLIBCXX 3.4.25, and CXXABI 1.3.11.
- Runtime manifests bind the private Node and Linux library paths. Cached or
  interrupted installs are reusable only when the whole private runtime is
  present.
- Wrapper activation switches Node, the AgenC entrypoint, and the private
  library path in one crash-safe transaction.
- Modern private-Node runtimes never invoke the retired single-binary
  auto-updater. Standalone users update through `agenc update`; npm and
  Homebrew installations stay on their package-manager update paths.
- The release SBOM enumerates every shipped Node distribution and both Linux
  `libatomic` components with checksums, licenses, and toolchain relationships.
- The frozen 0.7.2 compatibility bridge remains byte- and shape-compatible and
  still requires host Node 25.9 when explicitly selected.
- Standalone version selection rejects the retired 0.8–0.10 host-Node
  contracts and the unpublished 0.11.0 source tag. The in-runtime updater
  accepts private-Node releases 0.11.1 and newer.

## Upgrading

The 0.10.0 standalone updater was published for Node 25 / ABI 141 and cannot
select a Node 26 / ABI 147 artifact. Upgrade an existing standalone install by
rerunning the installer; it preserves `AGENC_HOME` and atomically repoints the
generated wrapper:

```sh
curl -fsSL https://get.agenc.ag/install.sh | sh
agenc daemon restart
```

On Windows:

```powershell
iwr -useb https://get.agenc.ag/install.ps1 | iex
agenc daemon restart
```

npm consumers must first run host Node.js `>=26.5 <27`, then install
`@tetsuo-ai/agenc@0.11.1`. Building the SDK from source uses the same host-Node
range; SDK publication remains an independent release. This host requirement
does not apply to the standalone installers.

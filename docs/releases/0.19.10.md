# AgenC 0.19.10

AgenC 0.19.10 names DeepSeek's new Flash model, adds it on OpenRouter, and
fixes reopening a session while its reply is still streaming.

## DeepSeek V4.1 Flash-1017

- DeepSeek now serves DeepSeek-V4.1-Flash-1017 under `deepseek-flash`, which
  is AgenC's default DeepSeek model, so DeepSeek sessions already use it with
  nothing to change. The model picker now shows its name. Context, output
  limit, effort levels and prices are the same as before.
- On OpenRouter it has its own id, `deepseek/deepseek-v4.1-flash-1017`, now in
  AgenC's OpenRouter catalog.
- On a small "make the failing tests pass" task (median of 4 runs), AgenC took
  17.4 s and $0.0058 with 1017. The day before, with the previous V4.1 Flash,
  it took 25.2 s and $0.0068.

## Fixes

- Closing the terminal while a reply streams and then running
  `agenc --continue` could fail with "canonical resume source ... changed
  during authorization", because the daemon was still writing the session.
  AgenC now accepts what the daemon appended; a replaced or rewritten session
  file is still refused.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.10`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

# AgenC 0.19.29

AgenC 0.19.29 keeps prompt caches valid through long sessions, most of all on DeepSeek, and sends images from file
reads, pastes and MCP tools in a smaller form. Native DeepSeek Flash in Light can write whole files with `Write`, and
`apply_patch` accepts hunks listed out of file order. Memory recall works on providers that cannot run the memory
selector, and helper requests are checked against each provider's limits before anything is sent or counted.

## Prompt cache

- On native DeepSeek, a tool result keeps the form it was first sent in until compaction, so trimming old tool output
  no longer rewrites the cached prefix of every later request. Other providers trim old tool output as before (#3390).
- Native DeepSeek keeps reasoning-only assistant messages in history by default, such as a response that hit the
  output cap before recovery, as DeepSeek's thinking-mode contract requires. Recovery that briefly turns thinking off
  keeps that reasoning too, so the next request still extends the cached one. Set
  `AGENC_DEEPSEEK_REASONING_ONLY_REPLAY=0` to turn this off for diagnostics (#3390).
- Native DeepSeek Light sends the full core tool schemas and the `write_stdin` and `kill_process` companions with
  its first request. Picking a core tool or starting a background command no longer changes the tool list ahead of
  the history, and AgenC no longer announces those tools as newly available (#3390).

## Images

- Images that FileRead returns, images in MCP tool results and images pasted or dropped into the terminal are
  normalized once, when they arrive. They keep up to 1568 pixels, and opaque images over 64 KiB, including ones with
  a fully opaque alpha channel, are re-encoded as JPEG quality 85 when that is smaller. Transparency, animation and
  photo orientation are kept (#3390).
- On providers with prompt caching, sent images stay unchanged while they fit in the 6 MiB image budget. When a new
  image does not fit, the oldest images leave in one batch, down to half the budget, and the current turn's images
  are kept first. An image that cannot fit next to the newer images of its own request gets a notice naming the
  file (#3390).
- On a 24-stage image-heavy browser task with DeepSeek Flash, fresh input fell 55.1% against 0.19.28 (155,406
  against 346,476 tokens on average) and the cache hit rate rose from 95.6% to 98.2%, with no history rewrites.
  Every screenshot reached the model in both versions (#3390).

## Editing

- In Light, native DeepSeek Flash gets `Write` with its first request. It is directed to write new files and full
  rewrites with `Write`, to use `apply_patch` for partial changes, and to read all the files and screenshots it
  needs in one response. A lowercase `write` call is accepted (#3392).
- `apply_patch` accepts hunks listed out of file order when each is a plain replacement whose lines occur exactly
  once in the file and no two overlap. Hunks with @@ context lines, insertions or an end-of-file marker still need
  file order, and ambiguous, inexact or overlapping hunks are rejected without writing (#3392).
- On a long three.js app task with DeepSeek Flash, the cache, image and editing changes together finished all 21
  checked behaviors in both runs, in 82.7 and 74.4 minutes. The 0.19.28 run reached the 120-minute limit with 11
  of 21 (#3392, #3393).

## Memory recall and helper requests

- When a provider cannot produce the memory selector's structured output, as on DeepSeek, AgenC uses deterministic
  lexical recall for that provider and model for the rest of the session and shows one notice. Selector requests
  rejected locally are no longer counted or held as cost (#3381, #3391).
- Helper requests (summaries, compaction, memory extraction, permission classification, MCP sampling and reviewers)
  are checked against each provider's image, tool and schema limits before admission. A request the provider cannot
  accept fails locally with a clear diagnostic and no charge (#3391).

## Other fixes

- The container resource note in the system prompt is shorter and keeps the CPU and memory limits.
- The installer shows the permissions it needs and the commands to repair them (#3218).
- AgenC resumes an unfinished task after a reply that contains only whitespace (#3238).
- The batch `Edit` path is kept when a hook only echoes `file_path` (#3382).
- Observation admission checks deadlines the same way as acquisition (#3387).
- Oversized web search responses are rejected while they stream, before they are read in full (#3388).
- `/grok-login` takes effect in sessions that were already open (#3389).

# AgenC 0.19.6

AgenC 0.19.6 makes the default TUI faster and much lighter on tokens, and
fixes problems in the Venice and Ledger menus and in long sessions.

## Faster and lighter

- Each request is about half the size. Standard mode now sends 12 tools on
  every call instead of 33. Helper agents, background process tools, web
  tools and rarely used tools load on demand when a task needs them. On
  DeepSeek the first request went from about 17,500 tokens to about 8,600.
- The model is asked to batch independent reads and commands, and to keep its
  final report short. On small tasks it no longer starts a separate
  verification helper.
- On a small "make the failing tests pass" task with DeepSeek V4 Flash,
  0.19.5 took 30.6 s and 203,000 tokens. 0.19.6 takes 24.1 s and 103,000
  tokens. With GPT-6 Luna the same task went from 241.7 s and 755,000 tokens
  to about 80 s and 130,000 tokens on runs without provider stalls.
- On a set of 10 everyday coding tasks, wall time fell 8 percent, cost 10
  percent and tokens 42 percent. On a separate held-out set of 12 tasks, wall
  time fell 17 percent, cost 13 percent and tokens 46 percent. The same tasks
  were solved: 127 of 128 runs against 128 of 128 before.
- When you type a prompt, the first request goes out about 0.1 s after you
  press Enter. The TUI now prepares its session while you type, and AgenC no
  longer waits for a provider's model list before the first request.
- On macOS each shell command starts about 35 ms sooner, because the sandbox
  helpers for the next command are prepared while the current one runs.
- On Linux, AgenC forces its session database to disk about half as often
  during a turn, and file reads wait less behind those disk flushes.
  Everything is still flushed at the end of each turn. After a power loss or
  system crash, resuming continues from the last saved step, and a command
  that was running is marked for review instead of being run again.
- In large repositories, checking whether the shell already showed a file now
  happens only when an edit needs it, not after every command.

## Fixes

- The Venice provider menu lists every Venice model that can call tools,
  about 130, instead of 3. It refreshes after you save, replace or remove a
  key, and any listed model can be selected. Venice models use Venice's
  published prices for the cost estimate and the budget check. A model with
  no published price shows "price unknown".
- Coding prompts that mention a ledger, such as a file named `ledger.txt` or
  accounting code, no longer open the Ledger hardware-wallet screen or check
  for a device. The screen opens for the Ledger commands and for questions
  about your Ledger device. While it is open, Esc, `/exit` and Ctrl+C work.
- A prompt too large for the model's context is refused before it is sent or
  saved, with its size and the limit.
- When a model's stream is cut off before any tool ran, AgenC retries it
  instead of failing the turn.
- A partly streamed answer stays visible when you detach from a session and
  reopen it.
- A model stream that turns into repeated nonsense is stopped early and
  retried once, instead of running and billing for minutes. Set
  `stream_degenerate_guard = false` to turn this off.
- Terminal color codes are removed from the command output the model sees.
- A mistyped model name on a provider with a fixed model list is refused with
  a suggestion for the closest name.
- Quitting the TUI before sending a prompt no longer leaves an empty session
  behind, and `agenc --continue` never resumes an empty session.
- With a custom endpoint, a session switches to the endpoint's real context
  and output limits at its next turn. Until then it uses the built-in limits
  for known models. Limits you set in the config always apply.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.6`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

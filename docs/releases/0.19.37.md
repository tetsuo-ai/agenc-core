# AgenC 0.19.37

AgenC 0.19.37 keeps text written for the model out of the UI: answers, denials, plan choices and tool results show
as plain user text. The terminal title follows `/model`. The daemon no longer freezes for 19 to 25 seconds while
sub-agents start, which also fixes print mode in swarms. The swarm cost display is exact, and ChatGPT sign-in shows as
plan. New OpenAI and DeepSeek switches are opt-in and off by default.

## Swarms and print mode

- Starting a sub-agent no longer freezes the daemon. Each model picker read the OpenRouter key from the keychain
  about 300 times, also in DeepSeek and OpenAI sessions. It now reads it once. On GPT-6.1 Sol the longest stall at a
  spawn fell from 19 to 25 seconds to about 0.2 seconds, and print-mode swarms that failed 4 of 4 times passed 5 of 5
  (#3589).
- Print mode waits up to 30 seconds for the daemon to admit a run and acknowledge output, and checks the daemon with
  a heartbeat while the model is quiet. A lost connection fails at once, without running the prompt again. Timeout,
  disconnect and protocol errors each have their own message (#3589).
- Local slash commands such as `/cost`, `/stats`, `/status` and `/model` only work in the TUI. Print mode refuses them
  with a message and exit status 1, also with `--continue` and stream-json input. They never reach the model. `/goal`
  keeps its print route (#3589).
- `AGENC_SPAWN_RESPONSIVENESS=off` and `AGENC_PRINT_STALL_RECOVERY=off` restore the old behavior, for diagnostics only
  (#3589).

## TUI

- Text written for the model no longer reaches the user. An answered question shows the question and the answer, a
  skipped one shows `Questions skipped`, a denied permission shows `Permission denied.`, and a plan choice shows
  `Plan approved` or `Keep planning`. The expanded view (ctrl+o) and `/resume` previews follow the same rule
  (#3592).
- Real command output, file text and the user's own messages show as written, including text that looks like a tag.
  A rejection keeps the user's reason, and a send failure keeps its recovery steps (#3592).
- Progress summaries, notifications and approval cards show readable fields instead of argument JSON. The exact
  arguments stay one keypress away in a separate view (#3592).
- The terminal title follows `/model`. It was computed once at startup, so after a switch it named the old model
  while the requests went to the new one (#3592).
- `/resume` lists only the user's own sessions, not memory sub-agent sessions. Unnamed collaboration agents get a
  local number instead of a thread id (#3592).
- In plain-text print output a lost daemon connection reads `Connection to AgenC closed before the answer finished.`
  JSON and stream-json output keep the full disconnect evidence (#3592).

## Cost

- ChatGPT sign-in calls count as plan, with no per-token charge. The status line reads, for example,
  `ctx lead 3% · swarm cache 90% · swarm $1.12 billed off-peak · ChatGPT plan` (#3593).
- `billed` is always shown and is an estimate of token and tool charges, not an invoice. `swarm` means the figure
  covers the lead and its recorded sub-agents, finished ones too. `ctx` is the lead's own context, never a sum
  (#3593).
- `/cost` lists billed money apart from plan usage, totals by provider and model, and one row per agent and model.
  For ChatGPT sign-in it also shows what the same calls would cost on an API key, for comparison only
  (#3593).
- Off-peak hours apply per call, from its dispatch time. DeepSeek web-tool fees keep their full price. A plan call
  that failed before it reported usage no longer marks the total with `≥` (#3593).
- `agenc -p --output-format json` reports the same ledger totals as `/cost`, sub-agents included, with
  `billedEstimateUsd`, `planCalls` and `apiEquivalentUsd` when the ledger has them (#3593, #3595).
- `AGENC_PLAN_ACCOUNTING=off` stops recording the new annotations. Budget limits keep their conservative basis.
  Provider requests are unchanged (#3593).

## OpenAI

- New opt-in: `AGENC_OPENAI_PRINT_PRECONNECT=1` opens the Responses socket as soon as the print-mode provider exists,
  while the session still starts. The first call started 58% sooner in our measurement, but the task time did not
  improve, so it stays off (#3590).
- New opt-in names for `AGENC_OPENAI_LIGHT_OUTPUT`: `exec-timeout` hides `timeoutMs` from the short `exec_command`
  declaration (it is still accepted), and `exec-results` drops the timing and token footer from command and poll
  results. Output, status, handles and warnings stay. No gain is proven yet, so both are off by default (#3591).
- Other providers send the same requests as in 0.19.36.

## DeepSeek

- New opt-in: `AGENC_DEEPSEEK_SUBSHELL_BACKGROUND_GUARD=1` refuses a command that starts a job in the background
  inside a subshell and never waits for it, such as `(server &)`, before it runs. Command cleanup would end that job.
  The refusal tells the model to use `background: true`. It is off by default, applies to DeepSeek sessions only and
  changes nothing else (#3594, #3595).

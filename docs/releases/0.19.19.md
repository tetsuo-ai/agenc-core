# AgenC 0.19.19

AgenC 0.19.19 recovers headless runs from more transport failures and keeps
the daemon running when a command uses too much memory. Standard mode sends a
smaller first request, the daemon does less work between model calls, and
Light works better with abliteration.ai Large V2. Headless JSON runs can also
turn on the completion check.

## Transport recovery

- In headless one-shot runs (`agenc -p`, including Light), a cut model
  stream, a 5xx response or a dropped or refused connection no longer ends the
  turn. The turn continues in the standard loop, which retries within the run
  deadline and the shared reconnect limit. No tool runs twice (#3302).
- A connection reset during a one-shot reply is now retried as a new request.
  Before, the retry was refused with `provider_call_failed_after_dispatch`. The
  failed attempt still counts toward the task budget (#3302).

## Memory pressure

- On Linux, commands that AgenC starts get a higher out-of-memory score than
  the daemon. When memory runs out, the kernel stops the command first, and
  the daemon stays up to report the failure instead of ending the run. The
  score is only raised, never lowered, and needs no extra privileges (#3302).

## Completion check in headless JSON runs

- Runs with `--output-format json` or `stream-json` can now use the
  completion check. The first answer is held and returned unchanged unless
  the check marks it as changed; then one more request produces the
  corrected answer. It is off by default. Set
  `completion_gate.exact_output = "verify"` to turn it on (#3302).
- In measured benchmark trials the check changed no result and added about
  one model call and six seconds per checked run, so the default keeps the
  existing behavior (#3302).
- For every checked turn, the check no longer starts a round that cannot
  finish before the run deadline's reserve (#3302).

## Smaller standard-mode requests

- Interactive standard sessions with no saved memories now get the memory
  rules only when a request is about memory, as Light already did. Runs
  without a person keep them. The /rewind undo paths also arrive only when
  needed, and the auto-mode reminder is folded into the bypass note. In the
  measured tasks the first request fell from 5,454 to 4,550 input tokens on
  DeepSeek and from 4,606 to 3,776 on Luna (#3303).
- Mentioning yourself in passing, for example "I'm new to this repo", no
  longer loads the memory rules. In the measured task this saved about 360
  tokens on every model call (#3303).
- The first note about stopped processes in a session says nothing is left to
  stop and how to check a server in one bounded command; later notes are one
  line. A command that waited a fixed time for a program it started gets the
  same guidance once (#3303).

## Less waiting between model calls

- While a new session waits for its first prompt, the daemon loads the code
  that prompt needs. The bubblewrap namespace and help probes run once per
  sandbox context instead of once per policy (#3304).
- During a turn, session snapshots and the rollout index are written in
  batches, and daemon heartbeats after the first are written off the main
  thread. Nothing that recovery reads changes its durability or order (#3304).
- In replays of the race tasks, the first request left about 30 ms sooner
  after Enter (median 94 to 63 ms) (#3304).

## abliteration.ai Large V2 in Light

- Light sessions on `abliteration:abliterated-model-large-v2` check a server
  in one command (start it, query it and stop it) and never `wait` on a
  server. They use batch Edit, read every file they will change in one
  response, and fix all failures they can diagnose before running the tests
  again. Requests for other models are unchanged until a command yields
  (#3250).
- For every model, a command that hits its time limit now reports
  `timed_out=true` with its exit code, and a stdin-closed error names all
  three ways to continue. In Light, a command that yields can be stopped with
  kill_process (#3250).

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.19`; Homebrew installations with
`brew upgrade tetsuo-ai/agenc/agenc`. Then run `agenc daemon restart`.

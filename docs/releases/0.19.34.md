# AgenC 0.19.34

AgenC 0.19.34 runs on Windows PCs with Smart App Control turned on and updates in place even when an old `agenc`
launcher comes first on PATH. The chat screen follows the terminal's theme, has more contrast and is calmer: your sent
messages sit on a band the color of the input box, tables are lighter, queued messages wait inside the input box and
the line after a turn is short again. On native DeepSeek the lean Light request becomes the default, and Light on
GPT-6 models asks for short answers.

## Windows

- AgenC starts and answers on Windows with Smart App Control on. Smart App Control blocks native files that have no
  signature and no reputation, and it blocked the state database module (`better_sqlite3.node`) of 0.19.32 and
  0.19.33, so the daemon could not open its state. On Windows the state database now uses the SQLite built into
  Node. Other platforms keep better-sqlite3 and fall back to the built-in engine when it cannot load.
  `AGENC_SQLITE_BACKEND=node|native` chooses one. Existing database files are unchanged (#3559).
- Stopping a terminal process on Windows no longer waits 5 s for a helper that Smart App Control blocks (#3559).

## Updates

- `/update` and `agenc doctor` look at every `agenc` on PATH, in order, and find the launcher that started AgenC even
  when an older one comes first. `/update` then offers Update now instead of printing install steps (#3557).
- install.sh moves aside an older AgenC launcher that would shadow the new one, and only when it is exactly an AgenC
  launcher for the same AgenC home. Any other file is reported and left alone (#3557).

## Chat screen

- The default theme is now auto: olive on dark terminals, light on light ones. AgenC asks the terminal for its
  background before the first frame and while it runs, and repaints everything when the theme changes. A saved theme
  choice is kept (#3560).
- Each theme has its own selection colors, so text you select with the mouse stands out, and gray text that was hard
  to read on dark and light terminals has more contrast (#3560).
- The terminal's answers to the background check no longer count as pasted input, so a direct shell command no longer
  asks for a paste confirmation without a paste (#3568).
- Your sent message sits on a band the color of the input box, with an empty row above and below it and without the
  prompt caret. The input box keeps its caret (#3561, #3566, #3570).
- A list item that wraps continues under its own text, not under its number (#3561).
- The footer shows the folder name instead of a cut path, and shows no ZDR badge until the status is known (#3561).
- While AgenC works, three dots light up in turn on the Working line. A running tool or agent shows a slowly fading
  dot instead of a spinning star, and a finished step keeps its solid dot (#3561, #3569).
- Tables have a thin gray frame with rounded corners, bold headers, one rule under the header and no lines between
  rows. When a row wraps, an empty framed line separates the rows (#3558).
- Messages you send while AgenC is still working wait inside the input box, numbered under a "next" header, with the
  shortcut that drops the last one. After five entries a count shows how many more are queued (#3562, #3571).
- The line after a turn is short again, as in 0.19.32: "done in 12s", plus the number of model calls when there was
  more than one. `tui.turnStats = "full"` in config.toml brings back the 0.19.33 line with input and cache figures,
  and the live line while a turn runs. `/cost` still shows the session totals (#3564).
- Shell result rows say what happened in words: "still running", "no output", "running in the background", "timed
  out after 30s" or "stopped by a signal", instead of a bracketed footer. What the model receives is unchanged (#3565).

## Sub-agents

- Spawned and waiting rows stop animating once their agents finish, and an interrupted agent no longer shows as
  running. The internal memory extraction agent is no longer counted as one of your agents, so the footer, the stop
  shortcut and the turn summary only count agents you started (#3556).

## Models

- Native DeepSeek Light sessions use the lean request by default: a minimal system text, the core tools with short
  definitions and compact tool results. Headless runs (`agenc -p`) also start at low effort when none was chosen and
  edit files through the shell. Interactive sessions keep Write and apply_patch, the full permission text and tool
  search. `light_request = "full"` or `AGENC_LIGHT_REQUEST=full` keeps the full request (#3563).
- OpenAI's native verbosity setting is now sent on the ChatGPT backend too, and Light sessions on GPT-6 models default
  to low verbosity when `model_verbosity` is not set. A configured level wins. Other providers are unchanged (#3567).

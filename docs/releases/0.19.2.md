# AgenC 0.19.2

AgenC 0.19.2 fixes problems found while testing 0.19.1 on clean installs on
macOS, Linux and Windows.

## Fixes

- On macOS, `agenc daemon restart` no longer leaves launchd restarting the
  daemon every few seconds. The installer and `brew services` run the daemon
  as a launchd job that restarts it whenever it exits. The restart command
  used to start its own copy, so the job's copy refused to run and exited,
  and launchd started it again, without end. Every start from the CLI or the
  TUI now goes through the launchd job when one runs that AgenC home.
- Starting AgenC in your home folder no longer says that trusting it turns on
  settings "this repo ships". Those were your own settings in
  `~/.agenc/config.toml`, which apply everywhere and need no trust.
- The Windows one-line installer finishes again. It looked for the pinned
  GitHub CLI in a folder its Windows zip does not have, and flushing the
  unpacked runtime to disk failed with EPERM, so no Windows install could
  complete.
- `agenc update` and npm installs on Windows work again. They had the same
  GitHub CLI problem, and their check that the system `tar` is signed by
  Microsoft never received the file's path, so it always failed. `agenc
  update` also had the flush problem.
- The Windows installer works in Windows PowerShell 5.1, the shell Windows 11
  ships with. It stopped at "Could not load file or assembly
  'System.Net.Http'", and later steps also failed there: inline Node checks
  lost their quotes, empty arguments were dropped, and setting the private
  folder's permissions asked for an administrator privilege.
- `agenc security audit` on Windows no longer reports the AgenC home and its
  files as open to everyone. Windows controls access with ACLs, and the file
  modes it checked mean nothing there.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.2`. Then run `agenc daemon restart`.
On a Mac that ran `agenc daemon restart` on 0.19.1, this restart also ends
the launchd loop and hands the daemon back to launchd.

On Windows, `agenc update` from 0.19.1 or earlier cannot finish. Run the
one-line installer again instead:

```powershell
iwr -useb https://get.agenc.ag/install.ps1 | iex
```

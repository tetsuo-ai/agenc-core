# AgenC 0.9.3

Fresh installs now recover safely from common owner-controlled wrapper
directory permissions, and installer failures no longer dump embedded
implementation source into the terminal.

## Fixes

### Default wrapper directories repair safe owner permissions

- Existing default `~/.local` and `~/.local/bin` directories created under a
  group-writable umask are normalized before any runtime artifact is
  downloaded.
- Repair is limited to real directories owned by the current user and only
  removes group/world write access. Explicit shared/custom prefixes remain
  fail-closed instead of being silently changed.
- Directory identity is rechecked around the permission change to prevent
  symlink or replacement races.

### Installer failures stay concise

- Standalone installer errors now print the actionable message without the
  enormous embedded `data:` module stack.
- Unsafe explicit wrapper destinations fail before downloading hundreds of
  megabytes of runtime data.

## Distribution reliability

- Full releases now keep a private, resumable exact-SHA ledger. Expensive
  release acceptance runs once on the final merged commit and interrupted runs
  resume from the first unproven gate.
- A dedicated `installer-stable` promotion channel can ship a reviewed
  installer-only hotfix without rebuilding unchanged native runtimes or
  republishing npm.

There are no breaking configuration or API changes.

## Upgrading

```sh
agenc update                              # standalone installs
npm install -g @tetsuo-ai/agenc@latest   # npm installs
```

Restart an already-running daemon after updating:
`agenc daemon restart`.

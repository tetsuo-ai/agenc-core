# AgenC 0.19.11

AgenC 0.19.11 shows what your model calls really cost. Before, a call to a
model AgenC had no price for was shown at the highest rate AgenC knows, so
an OpenRouter call that cost a third of a cent could show 88 cents.

## Real costs

- OpenRouter: AgenC now shows the charge OpenRouter reports with every
  response. With your own provider key on OpenRouter, the provider's charge
  is added to OpenRouter's fee.
- Every model in the model picker now has a price. New prices: all Amazon
  Bedrock models (US East on-demand rates), Ollama Cloud, more Qwen and
  GitHub Copilot models, and GLM-5 Turbo on Z.AI.
- Calls that cost nothing per token now show $0: NVIDIA NIM's free API, the
  Qwen Token Plan, the GLM Coding Plan, and Grok Composer through Grok Build.
- Budget limits still reserve conservatively before a call and settle at the
  real price after it.

## Model list

- Hidden because the provider retired them or no longer sells them: six Qwen
  models Alibaba retired on 2026-10-10 (qwen-coder-plus, qwen-turbo,
  qwen3-8b, qwen3-14b, qwen3-30b-a3b, qwen3-235b-a22b), three Copilot models
  GitHub retired on 2026-10-02 (Gemini 3.5 Flash, Gemini 3.6 Flash, Kimi K2.7
  Code), and three Ollama Cloud models missing from Ollama's price list.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.11`. Then run `agenc daemon restart`.
On a Mac, if a dialog asks whether AgenC's node may access your Documents,
Desktop or Downloads folder, allow it so AgenC can reopen your sessions there.

# AgenC 0.9.5

Doctor now reports standalone installations accurately and gives Ubuntu users
an actionable, scoped fix when AppArmor blocks the required bubblewrap
sandbox.

## Diagnostics

- Canonical installer wrappers are matched to the exact runtime executing
  Doctor, so standalone installs report `native` and show the wrapper path
  instead of `unknown` and the Node interpreter.
- A single installation, including repeated entries caused by duplicate
  `PATH` segments, no longer appears under **Multiple installations detected**.
  Real side-by-side native and npm installs are still reported.

## Ubuntu sandbox readiness

- Doctor recognizes the Ubuntu AppArmor denial that surfaces as
  `Failed RTM_NEWADDR: Operation not permitted`.
- `agenc doctor --apparmor-profile` prints a per-command profile for the
  verified standalone wrapper. Doctor's remediation shows the exact `tee` and
  `apparmor_parser` commands needed to install it.
- The fix leaves AppArmor and the system-wide unprivileged-user-namespace
  restriction enabled.

There are no breaking configuration or API changes.

## Upgrading

```sh
agenc update                              # standalone installs
npm install -g @tetsuo-ai/agenc@latest   # npm installs
```

Restart an already-running daemon after updating:
`agenc daemon restart`.

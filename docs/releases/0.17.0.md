# AgenC 0.17.0

AgenC 0.17.0 makes clean daemon restarts preserve idle resumable work, adds
race-safe client synchronization in daemon protocol 1.2, and expands Linux
sandbox coverage with a Landlock fallback. It also keeps large tool results
useful without flooding model context, repairs Editor recovery, validates
local-model setup during onboarding, and hardens durable CSV, memory-index, and
cross-platform process state.

## Sessions and daemon lifecycle

- **Clean daemon restarts preserve resumable sessions.** Idle runs are durably
  suspended before shutdown and restored against their canonical rollout and
  workspace identity. Resume keeps the run epoch and its permission, model,
  provider, profile, effort, verbosity, service-tier, and hook settings instead
  of silently starting a different session. Cancelled work and operations with
  an unknown effect remain fail-closed.
- **Daemon lifecycle commands target one authenticated process instance.**
  Startup, replacement, reload, shutdown, and stale-process cleanup now use
  durable instance identity and serialized transitions, preventing an old
  command from stopping or attaching to a newer daemon.
- `--continue` and `--resume` seal and revalidate the exact rollout file and
  working-directory identity before reopening it. `agenc run start` is also
  visible in top-level help.

## Client protocol

- **Daemon protocol 1.2 is additive and backward-compatible with 1.0 and 1.1
  clients.** It adds `session.transcript.v2` with stable message/event
  identities and an epoch-plus-sequence watermark, plus authenticated
  `daemon.shutdown`.
- Prompt clients can supply a stable `clientMessageId` for durable idempotency,
  opt into fail-fast overlap handling with `ifBusy: "reject"`, and cancel only
  the expected active turn. Duplicate submissions report whether a durable
  terminal outcome exists instead of guessing after a crash or reconnect.
- Live events now carry the correlation fields needed to merge a snapshot with
  concurrent delivery safely. The in-tree SDK adds matching transcript,
  admission, cancellation, capability-negotiation, and error surfaces.
  `@tetsuo-ai/agenc-sdk` remains independently versioned at 0.3.0 and is not
  published by this Core release.

## Linux sandboxing

- **AgenC can fall back to Landlock when bubblewrap is missing or blocked by
  restricted user namespaces.** The bundled helper applies filesystem
  allow-lists and the same seccomp network filter used by the bubblewrap path
  without requiring a sudo-installed profile.
- `agenc doctor` reports whether Landlock is fully enforced, partially
  enforced, or unavailable. The fallback refuses policies Landlock cannot
  express rather than silently weakening them. Set
  `AGENC_DISABLE_LANDLOCK_FALLBACK=1` to retain the previous fail-closed
  behavior.

## Tools and Editor

- Repeating the same tool with identical arguments now produces non-blocking
  reminders at the third, fifth, and eighth call. The reminder is excluded
  from durable history and never prevents intentional polling.
- Large tool results are stored in the active conversation, represented by a
  compact head-and-tail preview so the final verdict remains visible, and
  surfaced with a warning if persistence fails. Operators can lower the
  offload threshold with `AGENC_TOOL_RESULT_OFFLOAD_BYTES`; the fixed wire cap
  is never raised.
- Fresh Editor navigation works through the documented Alt+H shortcut again.
  Orphaned Editor revisions can be refreshed and reconciled against exact disk
  fingerprints, while Neovim stays responsive through retryable workspace
  capture races.

## Models and onboarding

- Local-provider onboarding now verifies that the selected Ollama, LM Studio,
  or compatible model is actually present, with an actionable Ollama pull hint
  when it is missing.
- Ollama receives the configured context window, Grok 4.6 accepts its
  advertised `xhigh` effort tier, and remaining direct-xAI fallback paths now
  agree on Grok 4.6. Existing explicit model configuration is unchanged.

## Recovery and platform hardening

- CSV output publication and orphan recovery now remain identity-safe across
  crashes, inode reuse, target replacement, cancellation, and platform ACL
  differences.
- Full-corpus memory indexing is restartable and bounded under concurrent
  readers and writers. MCP startup handles early stdio EOF cleanly, detached
  Git maintenance is contained, and Windows process/tool identity checks use
  trusted absolute paths.
- Installer and launcher SQLite locking remain synchronized across shell,
  PowerShell, and npm-managed installs.

## Compatibility and migration

There is no breaking CLI or configuration migration in 0.17.0, and protocol
1.0/1.1 clients remain supported. Restart the daemon after updating so it
loads the new runtime and protocol.

State-database migrations 25 through 27 are automatic: they add CSV
writer/orphan accounting and durable run-suspension/runtime-settings
projections. Once 0.17.0 opens and migrates a state database, an older runtime
will refuse that newer schema by design. Back up `AGENC_HOME` before first
launch if rollback to 0.16.x must remain possible.

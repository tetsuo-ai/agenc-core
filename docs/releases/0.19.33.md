# AgenC 0.19.33

AgenC 0.19.33 makes long sessions spend fewer model calls on waiting, keeps long image-heavy sessions on the prompt
cache and keeps the first task through a compaction. It
adds an optional lean Light request for native DeepSeek, Meta Muse Ember, Qwen4 Max Preview and DeepSeek's app tools,
and keeps ChatGPT sign-in sessions on their cached prefix. The chat transcript draws tables, lists and emoji in the
right cells. The MCP SSE server now requires a token, the Telegram gateway is harder to misuse, retired models are no
longer offered, and file history for /rewind is repaired.

## Long sessions

- `exec_command` and empty `write_stdin` polls keep waiting while the command still uses CPU, up to 240 s, instead
  of returning after 30 s. They end early when input is queued, a deadline reserve starts or the command goes idle.
  This is on in Light sessions; `AGENC_EXEC_WAIT_WHILE_BUSY` switches it (#3430).
- An automatic compaction keeps earlier user prompts word for word: the first one, then the newest, up to 64 KB and
  never more than 5% of the context window. Before, only the live message survived (#3430).
- The compaction summary call asks for an answer without thinking where the route allows it, so it no longer runs out
  of its limit while reasoning. A refused summary is retried after 5, 10 and 20 model calls instead of turning
  compaction off for the rest of the turn (#3430).
- Max-output recovery retries only when it can raise the limit, and memory recall runs once per turn instead of
  before every model call (#3430).
- A partial file read says which lines it shows and how many lines the file has (#3430).
- The interactive screen shows the turn's model calls, input size and cached share while it runs, and in the footer
  when it ends (#3430).
- Three options are off by default: repeated reads of an unchanged range point to the earlier result
  (`AGENC_READ_DEDUP`), full command output goes to a private log (`AGENC_EXEC_OUTPUT_KEEP=log`), and a Light edit
  can carry a check command that runs right after it (`AGENC_EDIT_THEN_RUN=1`) (#3430).
- Long sessions with many images keep the provider's prompt cache. When images overflow, providers that cache an
  unchanged prefix now drop a larger batch at once, so evictions are rare, and native DeepSeek keeps up to 24 MiB of
  images inline (6 MiB elsewhere; `AGENC_CONTEXT_IMAGE_BUDGET_BYTES` sets it). Context pressure follows the prompt
  size the provider reported, and a compaction reuses the last request's cached prefix when it fits. In one long
  image-heavy run at max effort, uncached input fell from 1.01M to 0.10M tokens and cost from $0.700 to $0.415
  (#3553).
- Tool arguments that are valid JSON are no longer HTML-decoded. A shell command with `&lt;x&gt;` now runs as
  written, and file writes and patches keep literal entities. Escaped JSON is still repaired when the original does
  not parse (#3549).

## Lean Light request for native DeepSeek

- `light_request = "lean"` (or `AGENC_LIGHT_REQUEST=lean`) gives Light sessions on native DeepSeek a short system
  text, the core tools with short definitions, compact tool results and low effort when no effort was chosen. By
  default the model then edits files through the shell, with the check in the same call. On graded long tasks it cost
  about half of the normal Light request at the same score (#3547).
- The default stays `full`, and full requests are unchanged. Every safety rule stays in the lean text word for word,
  and the sandbox, protected files and approvals work the same in every edit mode (#3547).

## Providers and models

- Meta Muse Ember (`muse-ember-1.0`) is registered with its limits, effort levels and prices. Meta chat requests now
  send the conversation's `prompt_cache_key`, so Muse Spark and Muse Ember sessions keep reading the prompt cache
  instead of missing it on every other call (#3429).
- Gemini 4 Argon and Carbon and the Meta reasoning models wait up to 20 minutes for a silent response instead of
  Node's 5 minutes, so a long thinking call is no longer cut and sampled again (#3430, #3431).
- `gemini-4-carbon` is registered next to Argon with its prices, and the headless `result` line reports the run's
  tokens and cost (#3430).
- ChatGPT sign-in sessions send the conversation's cache key in a `session_id` header, so most calls read the prompt
  cache. On one graded task the cached share went from 17% to 91% (#3432).
- Qwen4 Max Preview (`qwen4-max-preview`, alias `qwen4.0-max-preview`) is registered on the QwenCloud Token Plan with
  its documented limits and effort levels; a saved `minimal` effort is sent as `low`. Structured output is off for it.
  AgenC stops offering it at 00:00 UTC on 2026-11-25, 16 hours before Alibaba ends the preview. Selecting it on
  pay-as-you-go `qwen` is refused with a clear error (#3546, #3552).
- DeepSeek's app tools, all off by default. Native DeepSeek sessions can use DeepSeek's server-side web search and
  URL reading (`providers.deepseek.app_tools = true` with web search on). Any provider can use DeepSeek Search and
  Fetch as the backend of AgenC's web tools, and DeepSeek OCR for text from PDF, Word, PowerPoint and image files in
  FileRead. An OCR upload needs an explicit approval for each file (#3548).
- A model past its retirement date is no longer listed or selectable. A session whose saved model retired still
  starts and shows a notice once (#3457).

## Terminal display

- Tables with emoji keep their borders in place, and a live session no longer corrupts letters on lines with emoji.
  Symbol widths now follow the Unicode width data, and the screen writer rewrites every cell such a character can
  cover (#3450).
- Tables keep words whole and fall back to key and value lines when they do not fit. Nested lists, code blocks and
  task boxes keep their layout (#3450).
- Queued inputs are one header line and a numbered list in gray, at most five entries (#3450).

## Gateway and MCP

- The MCP SSE server (`agenc mcp serve --transport sse` and the daemon's `[mcp.server]` SSE listener) requires
  `Authorization: Bearer <token>` on every request. The token is `AGENC_MCP_SERVER_TOKEN`, or one token per AgenC
  home kept in secure storage; `agenc mcp serve --print-token` prints it. A request with an `Origin` header is refused
  unless that origin is in `mcp.server.allowed_origins`. Existing SSE clients must send the header (#3456).
- Telegram chats run side by side, an owner's `/stop` is answered at once, and a long reply is sent as several
  messages instead of failing (#3455). Permission requests after the first 100 of a run are announced (#3451).
- An unreadable Telegram owner state now fails closed: public group replies are off, stored owners are ignored and
  `/owner` claims are refused. The state is saved with a temporary file and a rename, so a failed write keeps the
  previous state (#3452).
- Pairing codes are longer, and five wrong codes lock that sender out of pairing for 15 minutes (#3454).
- The injection filter no longer blocks ordinary questions. It only matches text aimed at the model's own
  instructions, and a blocked message gets a neutral reply (#3453).

## Sessions and files

- File history for `/rewind` copies only changed files, deletes backups that no snapshot uses, saves the state
  before a write before the write runs, and tracks `system.move` and `system.delete`. `system.move` refuses to
  replace an existing destination unless `overwrite: true` is passed (#3458).

## Dependencies and evaluation

- npm audit advisories are cleared in 18 of the 20 production packages it reported, among them shell-quote 1.11.0,
  tar 7.5.23, @modelcontextprotocol/sdk 1.32.2 and sharp 0.35.5. The two left, zod 3 and the sandbox runtime that
  needs it, need the zod 4 major (#3459).
- The public Harbor adapter runs AgenC the way the published Terminal-Bench 2.1 run did, with nothing private, and
  passes `--deadline` by default (#3428, #3433).
- The stale root REPORT.md and vercel.json are removed (#3449).

## Tests and release builds

- Tests and docs that the merged pull requests broke together are fixed: the retirement snapshot test counts only
  OpenRouter rows, `AGENC_DEEPSEEK_APP_TOOLS` is documented, and the DeepSeek app tools wire test follows the lean
  shell edit text (#3551).
- The release builds accept GitHub's new macOS 15 arm64 runner image 20261112.0539 (#3550).

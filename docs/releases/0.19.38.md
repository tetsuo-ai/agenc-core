# AgenC 0.19.38

AgenC 0.19.38 adds GPT-6.2 Astra and GPT-6.2 Sol on the OpenAI routes, with an API key and with ChatGPT sign-in.
The default model does not change. Other providers send the same requests as in 0.19.37.

## OpenAI

- `gpt-6.2-astra` and `gpt-6.2-sol` are in the model list and in `/model`. Both have a 1,050,000 token context
  window, up to 128,000 output tokens, text and image input, tool use, structured output and the Fast tier (#3598).
- Both accept the efforts `low`, `medium`, `high`, `xhigh` and `max`. AgenC sends the chosen effort as is on both
  routes. Ultra is a Codex mode that uses sub-agents, not a model effort, so it is not offered (#3598).
- Tool calls go through the Responses API. Chat Completions refuses function tools for both models, as OpenAI's
  migration guide says (#3598).
- Swarms pick GPT-6.2 Astra as a strong child model and GPT-6.2 Sol as a balanced one (#3598).
- Cost uses OpenAI's published prices. GPT-6.2 Astra costs $8 per million input tokens and $40 per million output
  tokens at Standard, with cache reads at $0.40 and cache writes at $10. Fast doubles every rate. Long context
  doubles the input and cache rates, and output costs $60. GPT-6.2 Sol has the same rates as GPT-6.1 Sol. Calls
  through ChatGPT sign-in count as plan, with no per-token charge (#3598).
- A `-pro` name is not priced as its base model, and `gpt-6.2-*` names on other providers get no OpenAI price
  (#3598).

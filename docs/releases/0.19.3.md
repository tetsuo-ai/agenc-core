# AgenC 0.19.3

AgenC 0.19.3 fixes problems found while using 0.19.2 on macOS and Linux.

## Fixes

- The Browser tool starts Chrome on macOS. Inside AgenC's sandbox, Chrome
  stopped the moment it started ("Google Chrome quit unexpectedly"), because
  macOS ends an app that cannot register with LaunchServices. The browser's
  sandbox profile now allows the system services Chromium needs to start and
  the names it gives its own processes. The clipboard, AppleEvents, the
  keychain, location, Spotlight, iCloud, notifications and the GPU stay
  blocked, and pages render in software.
- Inside AgenC's sandbox the browser runs with Chromium's own sandbox off,
  because Chromium's sandbox cannot start inside another one. AgenC's sandbox
  still confines the browser. On Linux you no longer need
  `[browser] no_sandbox = true`.
- A browser that fails to start no longer blocks the session. It used to
  leave an "outcome unknown" review that refused every new prompt. A launch
  that never reached a page now counts as having no effect.
- When a tool's outcome is unknown, a card at the prompt shows the tool and
  its error. Press 1 for "It had no effect", 2 for "It took effect" or 3 for
  "Keep blocked". Prompts you send meanwhile wait in the queue and run after
  the review, instead of being dropped. `/resolve` still works.
- A finished sub-agent no longer retries its report while a review blocks
  the session; the report goes through once the review is done. `agenc run
  status` reports `review_needed` instead of `running` for such a run.
- The footer shows how many agents are running, next to the shell count.
- The daemon no longer hangs at startup on a session folder that waits for a
  macOS privacy prompt or a slow network drive. It used to open every
  recovered session's folder before it was ready, while holding its startup
  lock, so `agenc daemon restart` and every TUI had to wait. Folders now open
  after the daemon is ready, with 10 seconds each. A session whose folder
  does not open stays listed and can be resumed later.
- When Chromium crashes at launch, the error says so, for example "Chromium
  was killed by SIGABRT during launch", instead of suggesting a wrapper
  script problem.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.3`. Then run `agenc daemon restart`.

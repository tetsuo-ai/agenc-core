How it works

Intent in. Diff out.

A tight loop from vague idea to verified change — without the ceremony.

  1. 01

    Install the CLI

    Get the daemon-backed AgenC launcher on your machine in one command.

  2. 02

    Open your repo

    Start AgenC where the code lives. It maps the tree, tests, and conventions.

  3. 03

    Plan, edit, verify

    Describe the outcome. AgenC plans, patches, runs checks, and keeps you in the loop.

  4. 04

    Ship

    Clean diffs, remembered context, ready for the next loop.

Workflow

Built for the way real code gets shipped.

AgenC stays in your terminal, respects your permissions, and keeps long-running work coherent with memory, plans, and independent verification.

  • Local-first by default Work happens in your repo with tools you can audit and approve.
  • Swarm when it helps Fan out research and implementation across agents with disjoint scopes.
  • Prove before done Verification agents challenge non-trivial changes before you ship.

Install

Get AgenC on your machine.

Use the self-contained standalone installer. Release artifacts are built from the committed lockfile in agenc-core.

# run in any repo

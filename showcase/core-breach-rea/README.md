# CORE BREACH: an AgenC Core and REA demo

CORE BREACH is a small first-person shooter, written entirely by AgenC Core 0.19.32 running DeepSeek V4.1 Flash at effort max, from the two prompts in this folder.

**Play it:** https://breach.agenc.ag (add `?attract=1` to watch it play itself)

## What is here

- **[PROMPT.md](PROMPT.md)**: the task.
  - AgenC Core got one file: DOOM.EXE from the DOOM v1.9 shareware release.
  - It also had [REA](https://github.com/morluto/rea), a reverse-engineering MCP server built on Ghidra.
  - It had no source code, no WAD data and no internet.
- **[FOLLOW-UP.md](FOLLOW-UP.md)**: one playtest message, sent afterwards in the same session.
- **[code/](code/)**: everything it produced, unedited.
- **[site/](site/)**: the Vercel config (security headers) and the notice served at breach.agenc.ag. The deployed site is code/game without verify.mjs, plus these files and code/LICENSE as LICENSE.txt.

## What it did

1. **Made the engine readable.** DOOM.EXE is a DOS/4GW Linear Executable, and Ghidra only saw its 16-bit extender stub. AgenC wrote [code/tools/le2elf.py](code/tools/le2elf.py) to turn the 32-bit program into an ELF file that REA could decompile. Two layout details in the prompt were wrong for this file; it noticed and adapted.
2. **Recovered the engine with REA.** That covers BSP traversal, wall clipping, floor and ceiling spans, distance lighting and sprite clipping, plus fixed-point math, the 35 Hz game loop, movement and collision, line of sight, doors and lifts, and the actor state machine. The addresses are in [code/REVERSE_NOTES.md](code/REVERSE_NOTES.md).
3. **Built a new game on it** in plain JavaScript:
   - [code/game/](code/game/): the renderer, the game logic, procedural textures and sprites, and Web Audio sound;
   - [code/tools/build-map.mjs](code/tools/build-map.mjs): its own map compiler;
   - [code/maps/reactor7.source.json](code/maps/reactor7.source.json): the level.
4. **Tested itself** with [code/game/verify.mjs](code/game/verify.mjs), 42 checks in headless Chromium.

## Run it locally

```bash
cd code/game
python3 -m http.server 8080
# then open http://127.0.0.1:8080/ (attract mode: http://127.0.0.1:8080/?attract=1)
```

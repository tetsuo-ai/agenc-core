# iot-builder

Optional AgenC plugin for IoT and embedded development. It contains the former
bundled `iot-builder` skill and its board, toolchain, workflow, and electrical
safety references.

Install from a checkout:

```bash
agenc plugin install ./plugins/iot-builder --scope user
```

The plugin is not installed or enabled by a clean AgenC runtime build. Add its
marketplace and install `iot-builder@agenc-first-party` to use the remotely
published version.
